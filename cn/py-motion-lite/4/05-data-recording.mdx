### 用普通读取还是实时会话

少量状态记录可使用第 3 章的普通读取接口。需要持续消费事件时，使用第 4.1 节的实时会话，检查事件的数据年龄及队列丢弃统计。循环读取次数不等于传感器产生的新样本数量。

### 示例任务：记录超声波距离

下一页例程只读取配套超声波，不发送运动指令。先完成 SDK、Token 和 USB 连接设置；运行前接好超声波模块。程序最多读取 100 次，写入当前工作目录下的新 CSV 文件，文件已存在时不会覆盖。

每行包含设备 ID、连接方式、主机记录时间、经过时间、有效性、状态、数据年龄和距离。距离单位为 mm，age 和经过时间的单位为 s。读取无效时，距离列留空。

循环内的 0.1 秒休眠是应用程序的等待时间，不是设备采样周期；调用耗时会使实际记录间隔更长。同一传感器快照可能被读取多次。

验证方法：打开输出 CSV，检查距离列有无有效数据；无效行应保留状态和时间信息。改变目标物距离后，比较有效距离的变化。若无有效数据，先按第 3.4 节检查模块和读取状态，再排查连接。

复现实验时保留原始 CSV，不直接覆盖。将清洗或绘图结果另存，并保留筛选规则。需要运动实验时，另外记录目标、实际反馈和停止原因，并遵守控制权与失效停止要求。

### 超声波 CSV 记录例程

<div style={{ background: '#f0fdf4', border: '1px solid #86efac', borderRadius: '4px', color: '#166534', display: 'inline-block', fontFamily: 'ui-monospace, SFMono-Regular, Menlo, monospace', fontSize: '0.78rem', fontWeight: 700, lineHeight: 1.2, margin: '0.7rem 0 0.25rem', padding: '0.22rem 0.45rem' }}>完整例程 · Python</div>

```python
import csv
import time
from datetime import datetime, timezone
import pymotion as pm

# 连接设备并记录 100 次超声波读数
stamp = datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%S%fZ")
filename = f"ultrasonic_{stamp}.csv"

with pm.lite.connect(transport="usb") as lite:
    with open(filename, "x", newline="", encoding="utf-8-sig") as f:
        writer = csv.writer(f)
        writer.writerow([
            "device_id", "transport", "host_utc", "elapsed_s",
            "valid", "state", "age_s", "distance_mm",
        ])
        start = time.monotonic()
        for _ in range(100):
            reading = lite.ultrasonic(max_age=0.5)
            usable = (reading.valid and reading.age is not None
                      and 0 <= reading.age <= 0.5)
            distance = reading.distance if usable else ""
            writer.writerow([
                lite.connection.device_id, lite.connection.transport,
                datetime.now(timezone.utc).isoformat(),
                round(time.monotonic() - start, 3),
                reading.valid, str(reading.state), reading.age, distance,
            ])
            f.flush()
            time.sleep(0.1)

print("记录完成:", filename)
```
