title: "4.2 实时命令"
---

实时命令用于在已经声明的端口范围内连续更新电机和 PWM 舵机目标，适合遥控、循迹和平滑速度变化。打开会话只建立命令通道，不会自动让执行器动作。

实时命令建议在 `lite.control()` 上下文中使用，以确保执行器控制权的正确获取。`frequency` 只控制实时数据，命令更新速度由程序调用 write() 的节奏决定，最高约 20 Hz；短时间连续写入多个目标时，SDK 优先发送最新目标。

### 4.2.1 支持类型

实时命令同样通过 `lite.realtime.open()` 创建会话，所有参数的完整说明见表 4-2。下文将 `lite.realtime.open()` 返回的 `RealtimeSession` 实例简写作 `session`。

只使用实时命令时，可保持 `data_sources=()`，并通过 `command_targets` 声明命令通道和允许控制的端口。

`command_targets` 是“命令通道名称到端口序列”的映射。配置命令通道只建立发送范围，不会自动让执行器动作。

command_targets = {

### 4.2.2 直流电机实时命令

开环 PWM控制、闭环速度控制使用以下API：

<div style={{ background: '#eff6ff', border: '1px solid #93c5fd', borderRadius: '4px', color: '#1d4ed8', display: 'inline-block', fontFamily: 'ui-monospace, SFMono-Regular, Menlo, monospace', fontSize: '0.78rem', fontWeight: 700, lineHeight: 1.2, margin: '0.7rem 0 0.25rem', padding: '0.22rem 0.45rem' }}>API 签名</div>

```python
session.commands.motor_pwms.write(mapping, *, valid_for)
session.commands.motor_speeds.write(mapping, *, valid_for)
```

停止当前实时命令通道中已声明的电机端口时使用以下 API：

<div style={{ background: '#eff6ff', border: '1px solid #93c5fd', borderRadius: '4px', color: '#1d4ed8', display: 'inline-block', fontFamily: 'ui-monospace, SFMono-Regular, Menlo, monospace', fontSize: '0.78rem', fontWeight: 700, lineHeight: 1.2, margin: '0.7rem 0 0.25rem', padding: '0.22rem 0.45rem' }}>API 签名</div>

```python
channel.stop()
```

mapping 与 `valid_for` 的完整说明见 4.2.4 节“write 通用参数”。

<div style={{ background: '#f0fdf4', border: '1px solid #86efac', borderRadius: '4px', color: '#166534', display: 'inline-block', fontFamily: 'ui-monospace, SFMono-Regular, Menlo, monospace', fontSize: '0.78rem', fontWeight: 700, lineHeight: 1.2, margin: '0.7rem 0 0.25rem', padding: '0.22rem 0.45rem' }}>完整例程 · Python</div>

```python
import time
import pymotion as pm

with pm.lite.connect(transport="usb") as lite:
    with lite.control():
        with lite.realtime.open(
            command_targets={"motor_pwms": (1, 2)},
        ) as session:
            channel = session.commands.motor_pwms
            channel.write({1: 30, 2: 30}, valid_for=1.2)
            time.sleep(1.0)
            channel.stop()  # 停止已声明端口
```

该示例通过 USB 连接设备，向 M1、M2 写入 30% 的开环目标并保持 1 秒，随后停止。`valid_for` 是单次目标的安全有效期；连续运动时应在目标到期前再次调用 write()。

### 4.2.6 数据与命令会话

同一个实时会话可以同时订阅数据并声明命令通道。参数含义分别见 4.1.2 和 4.2.1，下面是使用示例。

<div style={{ background: '#f0fdf4', border: '1px solid #86efac', borderRadius: '4px', color: '#166534', display: 'inline-block', fontFamily: 'ui-monospace, SFMono-Regular, Menlo, monospace', fontSize: '0.78rem', fontWeight: 700, lineHeight: 1.2, margin: '0.7rem 0 0.25rem', padding: '0.22rem 0.45rem' }}>完整例程 · Python</div>

```python
import pymotion as pm

# 同时打开实时数据与命令通道
with pm.lite.connect(transport="usb") as lite:
    with lite.control():
        with lite.realtime.open(
            data_sources=("line_tracker",),
            command_targets={"motor_speeds": (1, 2)},
            frequency="high", data_queue_size=32,
        ) as session:
            channel = session.commands.motor_speeds
            try:
                for _ in range(100):
                    event = session.data.read(timeout=0.1)
                    if event is None:
                        channel.stop()
                        continue
                    if event.source != "line_tracker":
                        channel.stop()
                        continue
                    reading = event.data
                    if (not reading.valid or event.age is None
                            or event.age > 0.2):
                        channel.stop()
                        continue
                    channel.write({1: 45, 2: 45}, valid_for=0.3)
            finally:
                channel.stop()
```

例程在循迹数据有效且足够新时，为 M1、M2 写入固定转速；否则停止。它演示数据驱动控制和失效处理，不是完整的循迹算法。
