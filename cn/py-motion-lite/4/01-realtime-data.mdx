实时数据会话会持续接收已订阅的传感器和设备状态，并把每次更新作为一条事件放入当前会话的等待队列。程序通过 read() 每次取出一条事件，适合连续显示、记录和控制。

`open()` 返回 `RealtimeSession`。只读取数据时，`data_sources` 至少包含一个数据源；如果同时配置了 `command_targets`，则可以将 `data_sources` 留空。

<div style={{ background: '#f0fdf4', border: '1px solid #86efac', borderRadius: '4px', color: '#166534', display: 'inline-block', fontFamily: 'ui-monospace, SFMono-Regular, Menlo, monospace', fontSize: '0.78rem', fontWeight: 700, lineHeight: 1.2, margin: '0.7rem 0 0.25rem', padding: '0.22rem 0.45rem' }}>完整例程 · Python</div>

```python
import pymotion as pm

with pm.lite.connect(transport="usb") as lite:
    with lite.realtime.open(
        data_sources=("imu", "power"),
        frequency="medium",
        data_queue_size=32,
    ) as session:
        print(session.data.sources)
        print(session.data.effective_rate_hz)
```

该示例只负责打开实时数据会话并查看实际订阅项和目标频率，不读取事件。Python 端队列默认保存 32 条尚未读取的事件；队列满时丢弃最旧事件。

`open()` 返回的 `session` 及其 `.data` 对象提供以下只读属性。

<div style={{ background: '#eff6ff', border: '1px solid #93c5fd', borderRadius: '4px', color: '#1d4ed8', display: 'inline-block', fontFamily: 'ui-monospace, SFMono-Regular, Menlo, monospace', fontSize: '0.78rem', fontWeight: 700, lineHeight: 1.2, margin: '0.7rem 0 0.25rem', padding: '0.22rem 0.45rem' }}>API 签名</div>

```python
session.sources
session.effective_rate_hz
session.data.sources
session.data.effective_rate_hz
```

- `session.sources`：类型为 `tuple[str, ...]`，表示本会话实际订阅的数据源名称。
- `session.effective_rate_hz`：类型为 `Mapping[str, float]`，表示每种已订阅数据源的目标有效频率，单位为 Hz。
- `session.data.sources`：同 `session.sources`，用于快捷访问。
- `session.data.effective_rate_hz`：同 `session.effective_rate_hz`，用于快捷访问。

两组属性指向相同的值，可从 `session` 或 `session.data` 上读取。

```python
import pymotion as pm

with pm.lite.connect(transport="usb") as lite:
    with lite.realtime.open(
        data_sources=("imu", "line_tracker", "power"),
        frequency="high",
    ) as session:
        print(session.effective_rate_hz)  # 各数据源的目标频率
```

high 表示请求最高档位，是 SDK 获取板卡传感器数据的频率，并不保证所有数据源的更新频率都达到 20 Hz。环境光、颜色和电源最高约 10 Hz，雷达约 6 Hz，设备状态约 0.5 Hz；TTL 状态受舵机数量和总线轮询影响，超声波的有效测距频率通常也低于 20 Hz。

IMU、五路循迹、电机状态和 PWM 状态在条件允许时可接近 20 Hz。实际接收速度还会受订阅数量、传感器测量时间和程序读取速度影响；effective_rate_hz 表示目标频率，不是对实际到达频率的保证。

<div style={{ background: '#f0fdf4', border: '1px solid #86efac', borderRadius: '4px', color: '#166534', display: 'inline-block', fontFamily: 'ui-monospace, SFMono-Regular, Menlo, monospace', fontSize: '0.78rem', fontWeight: 700, lineHeight: 1.2, margin: '0.7rem 0 0.25rem', padding: '0.22rem 0.45rem' }}>完整例程 · Python</div>

```python
import pymotion as pm

with pm.lite.connect(transport="usb") as lite:
    with lite.control():
        pwm = lite.pwm_servo(1, mode="speed")
        ttl = lite.ttl_servo(1, mode="position")

    with lite.realtime.open(
        data_sources=("motors", "pwm_servos", "ttl_servos"),
        pwm_servos=(pwm,),
        ttl_servos=(ttl,),
        frequency="medium",
    ) as session:
        for _ in range(6):
            event = session.data.read(timeout=1.0)
            if event is not None:
                print(event.source, event.data)
```

该示例同时读取直流电机、PWM 舵机和 TTL 总线舵机状态。创建 TTL 对象时会配置实际运行模式，因此对象初始化放在 `lite.control()` 中；后续实时会话只读取状态，不会主动让执行器动作。
