写操作正常返回（包括返回 None）表示设备已经返回命令级成功响应；设备明确拒绝时会抛出相应异常。命令级成功不等于机械机构已经物理到位，只有明确带有状态验证语义的结果才表示经过反馈确认。

遇到 `CommandOutcomeUnknownError` 时，不要直接重复运动命令。先保证现场安全并尝试停止输出；连接可用时重新读取最新状态，再决定是否重新执行。该异常不表示命令一定成功或一定失败，只表示 SDK 无法证明最终结果。

参数类型或范围错误通常抛出 `TypeError` 或 `ValueError`，应直接修正程序参数。

### 5.1.1 推荐异常结构

<div style={{ background: '#f0fdf4', border: '1px solid #86efac', borderRadius: '4px', color: '#166534', display: 'inline-block', fontFamily: 'ui-monospace, SFMono-Regular, Menlo, monospace', fontSize: '0.78rem', fontWeight: 700, lineHeight: 1.2, margin: '0.7rem 0 0.25rem', padding: '0.22rem 0.45rem' }}>完整例程 · Python</div>

```python
import pymotion as pm

# 获取电机对象并发送控制命令
try:
    with pm.lite.connect(transport="usb") as lite:
        with lite.control():
            lite.motor(1).set_speed(20, duration=1.0)
except (TypeError, ValueError) as exc:
    print("程序参数错误:", exc)
except pm.lite.AuthenticationError as exc:
    print("请检查设备 Token:", exc)
except pm.lite.DeviceNotFoundError as exc:
    print("请检查连接和设备 ID:", exc)
except pm.lite.CommandOutcomeUnknownError as exc:
    print("结果无法确认，不要直接重发:", exc.operation)
except pm.lite.LiteError as exc:
    print("设备操作失败:", exc)
```

不得用空的 except 忽略错误。记录异常并允许控制上下文完成清理；通信不可用或机构仍在运动时，应立即使用物理停止措施。
