本节将引导运行 Quick Start 中的例程，快速体验 PyMotion Lite 的连接、电机控制。完成本节后，请到第 3 章进一步学习各类执行器和传感器的基础。

### 2.3.1 确认连接

在 VS Code 中运行 `examples\quick-start\02-connection.py`，或在终端运行以下命令。

```powershell
python examples\quick-start\02-connection.py
```

在 Ubuntu 或树莓派上，请将路径分隔符改为 `/`，运行以下命令。

```bash
python examples/quick-start/02-connection.py
```

注意：运行本例程前，请确认已按 2.1 节完成 SDK 安装、已设置 `PYMOTION_AUTH_TOKEN` 环境变量、USB 线已连接设备与电脑，并且设备已上电。

### 2.3.2 第一次控制电机

按第 3.1 节接线图连接配套电机。断电接线，首次运行前架空车轮。

在 VS Code 中运行 `examples\quick-start\03-motor.py`，或在终端运行以下命令。

```powershell
python examples\quick-start\03-motor.py
```

运行前必须检查：1. 车轮已架空或卸下负载；2. 运动范围内无障碍物；3. 已接入外部电源（USB 供电不足以驱动电机）；4. 已准备好立即断电的手段。

预期行为

1. M1 以 30% 速度转动 2 秒，然后停止；
2. 将当前位置设为 0° 零点；
3. 转动到 90° 位置；
4. 再向回转 90°（回到零点附近）；
5. 程序结束，电机自动停止。
