读取 PyMotion Lite 设备状态时使用以下 API：

<div style={{ background: '#eff6ff', border: '1px solid #93c5fd', borderRadius: '4px', color: '#1d4ed8', display: 'inline-block', fontFamily: 'ui-monospace, SFMono-Regular, Menlo, monospace', fontSize: '0.78rem', fontWeight: 700, lineHeight: 1.2, margin: '0.7rem 0 0.25rem', padding: '0.22rem 0.45rem' }}>API 签名</div>

```python
lite.status(*, max_age=1.0)
```

停止全部执行器但不锁存急停状态时使用以下 API：

<div style={{ background: '#eff6ff', border: '1px solid #93c5fd', borderRadius: '4px', color: '#1d4ed8', display: 'inline-block', fontFamily: 'ui-monospace, SFMono-Regular, Menlo, monospace', fontSize: '0.78rem', fontWeight: 700, lineHeight: 1.2, margin: '0.7rem 0 0.25rem', padding: '0.22rem 0.45rem' }}>API 签名</div>

```python
lite.stop()
```

急停可使用 emergency_stop() 或其等价别名 estop()，解除急停使用 reset_estop()。这三个公开入口都返回 ActionResult：

<div style={{ background: '#eff6ff', border: '1px solid #93c5fd', borderRadius: '4px', color: '#1d4ed8', display: 'inline-block', fontFamily: 'ui-monospace, SFMono-Regular, Menlo, monospace', fontSize: '0.78rem', fontWeight: 700, lineHeight: 1.2, margin: '0.7rem 0 0.25rem', padding: '0.22rem 0.45rem' }}>API 签名</div>

```python
lite.emergency_stop()
lite.estop()  # 与 emergency_stop() 完全等价
lite.reset_estop()
```

```python
import pymotion as pm

with pm.lite.connect(transport="usb") as lite:
    status = lite.status()
    print(status.device_id, status.state)

    result = lite.stop()  # 停止全部执行器
    print(result.succeeded)
```
