# 验证测试页

这是一个最小验证页。如果你能在导航「产品手册」下看到它，并且当前显示的内容与你 push 的版本一致，说明 **本地 → GitHub → Mintlify 自动发布** 链路已完全打通。

## 这个页面在验证什么

1. 新建 `.mdx` 文件能被识别为页面
2. `docs.json` 中注册后出现在左侧导航
3. push 到 main 后站点自动更新
