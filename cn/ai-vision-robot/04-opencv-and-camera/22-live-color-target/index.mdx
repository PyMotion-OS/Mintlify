## 本页目标

静态图会了，改**实时**。坑在这里：`capture.read()` 是阻塞的，直接放在主循环里，画面一卡整个程序就僵住。本页用**后台线程持续取图 + 主程序挑新鲜帧**解决，并引入"图片年龄"和"帧编号"两个判据。

## 前置条件

- 一个可访问的 RTSP 摄像头（`CAMERA_URL` 要改成你自己的地址）
- 同目录有 `target_observation.py`（4.6 抽出的 `find_target` / `draw_target_marks`）
- 完成 4.6

## 动手步骤

**1. 新建 `22_live_color_target.py`**

**2. 写入核心代码**

```python
from datetime import datetime
import threading
import time
import cv2
from target_observation import draw_target_marks, find_target

CAMERA_URL = "rtsp://192.168.43.226:554/11"
MAX_AGE = 0.5      # 图片收到超过 0.5 秒就丢弃


def log_message(level, source, message):
    current_time = datetime.now().strftime("%Y-%m-%d %H:%M:%S.%f")[:-3]
    print(f"{current_time} {level:<7} {source:<8} {message}")


class Camera:
    def __init__(self, camera_url):
        self.camera_url = camera_url
        self.capture = None
        self.frame_data = {"image": None, "frame_number": 0, "received_at": None}
        self.is_running = False
        self.thread = None

    def __enter__(self):
        self.capture = cv2.VideoCapture(self.camera_url)
        if not self.capture.isOpened():
            self.capture.release()
            raise ValueError("摄像头连接失败，请检查地址和网络")
        log_message("INFO", "camera", "状态变为 connected")
        self.is_running = True
        self.thread = threading.Thread(target=self.update_image, daemon=True)
        self.thread.start()
        return self

    def update_image(self):
        # 后台线程：只管不停把最新图片塞进 frame_data，不关心主程序用不用
        while self.is_running:
            is_received, image = self.capture.read()
            if not is_received:
                log_message("WARNING", "camera", "状态变为 disconnected")
                self.is_running = False
                break
            self.frame_data = {
                "image": image,
                "frame_number": self.frame_data["frame_number"] + 1,
                "received_at": time.monotonic(),      # 单调时钟，不受系统校时影响
            }

    def latest_data(self):
        return self.frame_data.copy()                  # 浅拷贝：图片不复制像素

    def __exit__(self, exc_type, exc_value, traceback):
        self.is_running = False
        self.thread.join(timeout=2.0)
        self.capture.release()


def main():
    last_frame_number = 0          # 主程序已处理过的帧编号

    try:
        with Camera(CAMERA_URL) as camera:
            while camera.is_running:
                if cv2.waitKey(20) == 27:      # Esc = 27
                    break

                frame_data = camera.latest_data()
                if frame_data["image"] is None:
                    continue                    # 还没取到首帧

                age = time.monotonic() - frame_data["received_at"]
                if age > MAX_AGE:
                    continue                    # 画面已过期，不做识别

                if frame_data["frame_number"] == last_frame_number:
                    continue                    # 同一帧不重复识别

                last_frame_number = frame_data["frame_number"]
                target_data = find_target(frame_data["image"])
                cv2.imshow("Live color target - Esc to close",
                           draw_target_marks(frame_data["image"], target_data))
    except ValueError as exc:
        log_message("ERROR", "camera", str(exc))
    except KeyboardInterrupt:
        log_message("INFO", "camera", "Ctrl+C 主动结束")
    finally:
        cv2.destroyAllWindows()


if __name__ == "__main__":
    main()
```

**3. 运行，按 Esc 退出**，观察终端日志

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `CAMERA_URL` | str | RTSP 地址 | 形如 `rtsp://<ip>:554/11`，必须是本机网络能访问的 |
| `MAX_AGE` | float | 0.2～1.0 秒 | 越小越"实时"，太小会频繁丢帧导致画面不刷新 |
| `waitKey(20)` | int | 毫秒 | 既是窗口刷新间隔，也是 Esc 检测的轮询周期 |
| `daemon=True` | bool | — | 主程序退出时线程自动结束，不会挂住进程 |

## 数据结构

`latest_data()` 返回的 `frame_data`：

```python
{
    "image": <ndarray>,          # BGR 图像，还没取到首帧时为 None
    "frame_number": 137,         # 每取到一张新图就 +1，用来跳过重复帧
    "received_at": 12853.421,    # time.monotonic() 时间戳，用于算图片年龄
}
```

年龄不在字典里，由主程序现算：`age = time.monotonic() - received_at`。

## 预期效果与排查

窗口里的框连续跟着蓝色物体移动，终端只在连接/断开时打日志，不刷屏。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 画面卡住不动 | 主程序自己在 `read()` | 取图必须在后台线程里，主循环只读 `latest_data()` |
| 一直不刷新 | `MAX_AGE` 太小，帧全被判过期 | 放宽到 1.0 秒再看 |
| Ctrl+C 后进程不退 | 线程非 daemon 且 `join` 无超时 | 用 `daemon=True` + `join(timeout=2.0)` |
| 报"摄像头连接失败" | 地址错 / 网络不通 / 摄像头被别的程序占用 | 先用播放器验证地址 |
