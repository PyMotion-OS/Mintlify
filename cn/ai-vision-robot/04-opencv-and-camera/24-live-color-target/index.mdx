## 前置条件

- 已知摄像头 RTSP 地址（参考 4.2 前置条件），手机/摄像头与电脑同一 Wi-Fi

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `class Camera`（线程版） | 后台线程 `update_image()` 持续取图，主程序拿 `latest_data()` |
| `frame_data` 字典 | `image`/`frame_number`/`received_at` 一起更新 |
| `time.monotonic()` | 单调时钟，算图片年龄不受校时影响 |
| `MAX_AGE` 判断 | 图片超过 0.5 秒不识别；`frame_number` 去重 |
| `find_target` / `draw_target_marks` | 吸收 4.7 的观测与标记 |

### 运行方式


## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `CAMERA_URL` | str | `rtsp://...` | RTSP 地址 |
| `MAX_AGE` | float | 0.5 秒 | 图片超龄不识别 |
| `frame_number` | int | 只增 | 判断是否重复处理 |
| `received_at` | float | 单调时间 | 算年龄 |

> 本页产出 `target_observation.py`（实时目标观测）。
