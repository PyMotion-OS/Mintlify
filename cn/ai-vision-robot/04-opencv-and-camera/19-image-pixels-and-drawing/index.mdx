## 前置条件

- 同目录放一张 `camera_frame.jpg`（用 4.1 拍的即可）

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `load_image(path)` | `np.fromfile` + `imdecode` 读图，兼容中文路径 |
| `image.shape` | 返回 `(高, 宽, 通道数)`，NumPy 按「行、列」定位像素 |
| `image[Y, X]` | 取像素，`[Y, X]` 不是 `[X, Y]`（Y 是行、X 是列） |
| `cv2.circle` / `rectangle` / `arrowedLine` / `putText` | 画圆、矩形、箭头、文字 |

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `POINT_X, POINT_Y` | int | 960, 900 | 选中像素坐标，X 水平、Y 垂直 |
| `pixel` | list | `[B, G, R]` | 该像素的 BGR 值 |
| `image.shape` | tuple | (高, 宽, 通道) | NumPy 数组形状 |

> 本页产出 `load_image()`，模块四后续读图都用它。
