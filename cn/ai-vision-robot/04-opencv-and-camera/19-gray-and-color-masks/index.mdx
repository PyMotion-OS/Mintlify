## 本页目标

把阈值判断从"亮度"升级为"颜色"：BGR 转 HSV，用 `cv2.inRange()` 框出蓝色目标，再用 `bitwise_and()` 只留目标像素。**记住：选颜色一律在 HSV 里做，不要在 BGR 里调。**

## 前置条件

- 同目录有 `camera_frame.jpg`（画面里最好有蓝色物体）
- 完成 4.3

## 动手步骤

**1. 新建 `19_gray_and_color_masks.py`**

**2. 写入核心代码**

```python
from pathlib import Path
import cv2
import numpy as np

ROI_LEFT, ROI_RIGHT = 0.15, 0.85
ROI_TOP, ROI_BOTTOM = 0.15, 0.85
BLUE_LOW = (95, 80, 60)          # HSV 下限
BLUE_HIGH = (135, 255, 255)      # HSV 上限
BASE_DIR = Path(__file__).parent
IMAGE_PATH = BASE_DIR / "camera_frame.jpg"


def load_image(path):
    return cv2.imdecode(np.fromfile(path, dtype=np.uint8), cv2.IMREAD_COLOR)


def make_color_mask(image, left, top, right, bottom, low, high):
    roi_image = image[top:bottom, left:right]
    hsv_image = cv2.cvtColor(roi_image, cv2.COLOR_BGR2HSV)   # H:0-179, S/V:0-255
    color_mask = cv2.inRange(hsv_image, low, high)           # 范围内变白
    selected_image = cv2.bitwise_and(roi_image, roi_image, mask=color_mask)
    return roi_image, selected_image, color_mask


def main():
    image = load_image(IMAGE_PATH)
    height, width = image.shape[:2]
    left, right = round(width * ROI_LEFT), round(width * ROI_RIGHT)
    top, bottom = round(height * ROI_TOP), round(height * ROI_BOTTOM)

    roi_image, selected_image, color_mask = make_color_mask(
        image, left, top, right, bottom, BLUE_LOW, BLUE_HIGH)

    contours, _ = cv2.findContours(color_mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    contour_image = cv2.cvtColor(color_mask, cv2.COLOR_GRAY2BGR)
    cv2.drawContours(contour_image, contours, -1, (0, 140, 255), 4)

    cv2.imshow("ROI", roi_image)
    cv2.imshow("Selected Blue", selected_image)
    cv2.imshow("Blue Mask", color_mask)
    cv2.imshow("Contours", contour_image)
    cv2.waitKey(0)
    cv2.destroyAllWindows()


if __name__ == "__main__":
    main()
```

**3. 运行，看四张窗口**

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `BLUE_LOW` | tuple | `(H, S, V)` | H 95～135 大致覆盖蓝色 |
| `BLUE_HIGH` | tuple | `(H, S, V)` | S/V 上限通常给 255 |
| H 通道 | int | **0～179** | OpenCV 把 360° 色相压缩成 180 |
| S 通道 | int | 0～255 | 色彩浓度，光照弱时降低下限 |
| V 通道 | int | 0～255 | 亮度，太暗会把黑当目标 |

## 预期效果与排查

“Selected Blue”只剩蓝色物体，“Blue Mask”是对应的黑白图，轮廓图上能看到框住目标的橘色线。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 选不到目标 | H 范围偏了 | 先把像素值打印出来（`cv2.cvtColor` 后取该点）再定范围 |
| 连背景一起选中 | S/V 下限太低 | 提高 `S` 下限，或提高 `V` 下限排掉暗区 |
| 目标被切成两半 | 目标很亮/很暗 | 放宽 V 范围，或改用光照更均匀的场景 |
