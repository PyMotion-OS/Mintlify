## 本页目标

4.7 的摄像头一旦断网，`read()` 会一直阻塞、程序像死了一样，重连后还可能拿旧画面做判断。本页补三件事：**连接超时、读取超时、断流自动重连**，并且断流时立刻清空旧图。

## 前置条件

- 同上，一个可访问的 RTSP 摄像头
- 同目录有 `camera.py`（4.7 的 `Camera` 类）和 `target_observation.py`
- 完成 4.7

## 动手步骤

**1. 新建 `23_camera_age_and_reconnect.py`**

**2. 写入核心代码**

```python
import time
import cv2
from camera import Camera, log_message
from target_observation import draw_target_marks, find_target

MAX_AGE = 0.5                 # 图片有效期
RECONNECT_SECONDS = 1.0       # 断流后等多久再连


def connect(camera):
    """打开一次连接；成功 True，失败 False。"""
    capture = cv2.VideoCapture(
        camera.camera_url,
        cv2.CAP_FFMPEG,                                    # RTSP 必须走 FFmpeg
        [cv2.CAP_PROP_OPEN_TIMEOUT_MSEC, 3000,             # 建立连接最多等 3 秒
         cv2.CAP_PROP_READ_TIMEOUT_MSEC, 1000],            # 单次取图最多等 1 秒
    )
    if not capture.isOpened():
        capture.release()
        return False

    camera.capture = capture
    old_data = camera.frame_data
    camera.frame_data = {
        "state": "connected",
        "image": None,                            # 关键：新连接必须清空旧图
        "frame_number": old_data["frame_number"],
        "received_at": None,
    }
    log_message("INFO", "camera", "状态变为 connected")
    return True


def set_disconnected(camera):
    """标记断开并清空旧图，连续失败只打一次日志。"""
    old_data = camera.frame_data
    if old_data["state"] != "disconnected":
        log_message("WARNING", "camera", "状态变为 disconnected")
    camera.frame_data = {
        "state": "disconnected",
        "image": None,
        "frame_number": old_data["frame_number"],
        "received_at": None,
    }


def main():
    camera = Camera()

    try:
        while True:                                # 外层：重连
            if cv2.waitKey(20) == 27:
                break

            if not connect(camera):
                set_disconnected(camera)
                time.sleep(RECONNECT_SECONDS)      # 限制重试频率
                continue

            with camera:                           # 内层：当前连接
                while camera.is_running:
                    if cv2.waitKey(20) == 27:
                        return                     # return 会先走 with 的 __exit__
                    image = camera.latest(MAX_AGE)
                    if image is None:
                        continue
                    target_data = find_target(image)
                    cv2.imshow("Camera age and reconnect - Esc to close",
                               draw_target_marks(image, target_data))

            set_disconnected(camera)
            time.sleep(RECONNECT_SECONDS)
    except (ValueError, cv2.error) as exc:
        log_message("ERROR", "camera", str(exc))
    except KeyboardInterrupt:
        log_message("INFO", "camera", "Ctrl+C 主动结束")
    finally:
        cv2.destroyAllWindows()


if __name__ == "__main__":
    main()
```

**3. 运行，拔掉网线或关掉摄像头再开**，看终端是否先 `disconnected` 再自动 `connected`

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `CAP_PROP_OPEN_TIMEOUT_MSEC` | int | 3000 | 建立 RTSP 连接的超时，太短会误判失败 |
| `CAP_PROP_READ_TIMEOUT_MSEC` | int | 1000 | 单次 `read()` 超时，断网时靠它跳出阻塞 |
| `RECONNECT_SECONDS` | float | 1.0 | 重连间隔，太小会疯狂刷日志 |
| `MAX_AGE` | float | 0.5 | 图片有效期，超时即视为无效 |

## 数据结构

清空后的 `frame_data` 是**完整的空状态**，不是删字段：

```python
{
    "state": "disconnected",   # connected / disconnected
    "image": None,             # 断流即清空，避免拿停住的画面做控制
    "frame_number": 137,       # 累计编号保留，重连后继续累加
    "received_at": None,       # 无有效图片，年龄无法计算
}
```

## 预期效果与排查

拔网线后 1 秒内日志出现 `disconnected`，窗口停止刷新但程序不崩；恢复网络后自动 `connected`，画面恢复。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 断网后程序卡死 | 没设 `READ_TIMEOUT_MSEC` | 必须带 FFmpeg 超时参数打开 |
| 重连后画面是旧的 | 新连接没清 `image` | `connect()` 里把 `image` 置 `None` |
| 日志疯狂刷屏 | `RECONNECT_SECONDS` 太小 | 至少 1 秒 |
| Esc 无效 | 阻塞在 `connect()` 里 | 连接在主线程，3 秒内窗口不响应是正常的 |
