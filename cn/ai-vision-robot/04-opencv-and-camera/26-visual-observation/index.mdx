## 前置条件

- 完成 [4.8 摄像头延迟与重连](../25-camera-age-and-reconnect/index)
- 把 `camera.py`、`target_observation.py` 复制到本页目录

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `Camera()`（无参） | 地址已内嵌到类，`with Camera() as camera` 即可 |
| `camera.latest()` | 返回 0.5 秒内有效图，无图返回 `None` |
| `find_target(image)` | 默认找蓝色目标，返回状态和二维偏差 |
| `last_state` 去重 | 状态不变不重复打印日志 |

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `camera.latest()` | 方法 | 0.5 秒有效期 | 返回有效图或 `None` |
| `target_data["state"]` | str | target/lost | 目标状态 |
| `error_x / error_y` | float | -1~+1 | 二维偏差 |

> 本页是模块四的收口，`camera.py` + `target_observation.py` 成为模块五~八的视觉基础。
