## 模块目标

这个模块把"图像"变成"可用的观测值"。链路固定：**取图 → 裁 ROI → 色彩空间转换 → 掩膜 → 轮廓 → 算出目标位置**。后面舵机跟踪、二维码、YOLO 都在这条链路上换零件。

## 前置条件

- 一个 RTSP 摄像头（或手机 IP 摄像头 App），地址形如 `rtsp://IP:554/11`
- `pip install opencv-python numpy`
- 电脑与摄像头在同一网段

## 学习建议

1. 每个例程先跑通再改参数，改完再运行一次，观察输出变化
2. 例程有演化关系，建议按顺序完成——4.1 产出 `Camera` 类与 `log_message()`，4.2 产出 `load_image()`，4.3/4.4 的掩膜在 4.5 合并成 `target_mask.py`、4.6 扩成 `target_contours.py`、4.7 收拢成 `target_observation.py`，4.8 产出最终版 `camera.py`，4.9 把两者合成完整观测
