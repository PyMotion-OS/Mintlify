# 4 OpenCV 与摄像头

## 模块目标

这个模块把"图像"变成"可用的观测值"。链路固定：**取图 → 裁 ROI → 色彩空间转换 → 掩膜 → 轮廓 → 算出目标位置**。后面舵机跟踪、二维码、YOLO 都在这条链路上换零件。

## 例程顺序

| 例程 | 内容 | 关键点 |
| --- | --- | --- |
| 4.1 摄像头基础 | RTSP 取图、保存、显示 | `with Camera()` 资源管理 |
| 4.2 图像像素与绘制 | 像素坐标、BGR、画点框线 | OpenCV 坐标原点在左上 |
| 4.3 ROI 与灰度掩膜 | 裁剪 + 灰度阈值 | ROI 越小算得越快 |
| 4.4 灰度与颜色掩膜 | HSV 选蓝色、`inRange` | 颜色用 HSV 不用 BGR |
| 4.5 形态学与轮廓 | 去噪、找轮廓、取面积与中心 | 面积过滤掉小噪点 |
| 4.6 颜色目标观测 | 封装成 `TargetObservation` | 把图像处理变成结构化观测 |
| 4.7 实时颜色目标 | 连续帧观测 | 帧年龄与延迟 |
| 4.8 摄像头延迟与重连 | `age`、断流重连 | 判据是帧新鲜度 |
| 4.9 视觉观测 | 一次拿到完整观测包 | 完整数据结构 |

## 前置条件

- 一个 RTSP 摄像头（或手机 IP 摄像头 App），地址形如 `rtsp://IP:554/11`
- `pip install opencv-python numpy`
- 电脑与摄像头在同一网段
