## 本页目标

把"整张图"缩到"中间 70% 的 ROI"，再转灰度、按亮度阈值做掩膜，最后找轮廓。理解 ROI 的两个收益：**算得快**、**排除边缘干扰**。

## 前置条件

- 同目录有 `camera_frame.jpg`
- 完成 4.2，理解坐标与切片

## 动手步骤

**1. 新建 `18_roi_and_gray_mask.py`**

**2. 写入核心代码**

```python
from pathlib import Path
import cv2
import numpy as np

ROI_LEFT, ROI_RIGHT = 0.15, 0.85          # 用中间 70% 宽
ROI_TOP, ROI_BOTTOM = 0.15, 0.85          # 用中间 70% 高
GRAY_LIMIT = 130                          # 灰度 ≤130 的像素变白
BASE_DIR = Path(__file__).parent
IMAGE_PATH = BASE_DIR / "camera_frame.jpg"


def load_image(path):
    return cv2.imdecode(np.fromfile(path, dtype=np.uint8), cv2.IMREAD_COLOR)


def make_gray_mask(image, left, top, right, bottom, gray_limit):
    roi_image = image[top:bottom, left:right]                  # 裁剪，新图左上角重设为 (0,0)
    gray_image = cv2.cvtColor(roi_image, cv2.COLOR_BGR2GRAY)   # 三通道 → 单通道亮度
    _, gray_mask = cv2.threshold(gray_image, gray_limit, 255, cv2.THRESH_BINARY_INV)
    return roi_image, gray_image, gray_mask


def main():
    image = load_image(IMAGE_PATH)
    height, width = image.shape[:2]
    left, right = round(width * ROI_LEFT), round(width * ROI_RIGHT)
    top, bottom = round(height * ROI_TOP), round(height * ROI_BOTTOM)

    roi_image, gray_image, gray_mask = make_gray_mask(image, left, top, right, bottom, GRAY_LIMIT)

    contours, _ = cv2.findContours(gray_mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    contour_image = cv2.cvtColor(gray_mask, cv2.COLOR_GRAY2BGR)   # 单通道不能画彩色
    cv2.drawContours(contour_image, contours, -1, (0, 140, 255), 4)

    cv2.imshow("ROI", roi_image)
    cv2.imshow("Gray", gray_image)
    cv2.imshow("Mask", gray_mask)
    cv2.imshow("Contours", contour_image)
    cv2.waitKey(0)
    cv2.destroyAllWindows()


if __name__ == "__main__":
    main()
```

**3. 运行，对比四张窗口**

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `ROI_LEFT/RIGHT` | float | 0～1 比例 | 乘宽度得像素坐标，中间 70% 常用 |
| `ROI_TOP/BOTTOM` | float | 0～1 比例 | 与宽同理，作用于高度 |
| `GRAY_LIMIT` | int | 0～255，本例 130 | 越小越严格；配合 `THRESH_BINARY_INV` 时暗的先变白 |
| `THRESH_BINARY_INV` | 常量 | — | 反相阈值：≤阈值变 255，其余 0 |
| `RETR_EXTERNAL` | 常量 | — | 只取最外轮廓，忽略嵌套 |

## 预期效果与排查

四张窗口依次是：裁剪图、灰度图、黑白掩膜、橘色轮廓叠加图。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 掩膜全黑或全白 | 阈值不适合当前光照 | 调 `GRAY_LIMIT`，或先看灰度图的数值分布 |
| `drawContours` 报错 | 往单通道图上画彩色 | 先 `cvtColor(..., COLOR_GRAY2BGR)` |
| 轮廓太多碎片 | 噪点 | 下一例（4.5）用形态学开运算清理 |
