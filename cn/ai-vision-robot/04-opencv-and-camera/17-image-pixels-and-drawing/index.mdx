## 本页目标

建立最重要的空间直觉：**OpenCV 的坐标原点是左上角，X 向右、Y 向下**，像素值是 `[蓝, 绿, 红]`。然后在图上画一个红点、一个绿框和一组坐标轴做标注。

## 前置条件

- 同目录有 `camera_frame.jpg`（用 4.1 存一张改名即可）
- `pip install opencv-python numpy`

## 动手步骤

**1. 新建 `17_image_pixels_and_drawing.py`**

**2. 写入核心代码**

```python
from pathlib import Path
import cv2
import numpy as np

POINT_X, POINT_Y = 960, 900                 # 想查看的像素
BASE_DIR = Path(__file__).parent
IMAGE_PATH = BASE_DIR / "camera_frame.jpg"


def load_image(path):
    image_bytes = np.fromfile(path, dtype=np.uint8)      # 中文路径用 fromfile
    return cv2.imdecode(image_bytes, cv2.IMREAD_COLOR)


def main():
    image = load_image(IMAGE_PATH)
    height, width, channels = image.shape                # 高、宽、通道数
    pixel = image[POINT_Y, POINT_X].tolist()             # 注意是 [Y, X]

    print(f"图片尺寸: {width} × {height}")
    print(f"颜色通道: {channels}（BGR 顺序）")
    print(f"像素坐标: ({POINT_X}, {POINT_Y})  BGR: {pixel}")

    cv2.circle(image, (POINT_X, POINT_Y), 8, (0, 0, 255), -1)     # 红点，-1 实心
    cv2.putText(image, f"({POINT_X}, {POINT_Y})  BGR={pixel}",
                (POINT_X + 20, POINT_Y - 15), cv2.FONT_HERSHEY_SIMPLEX, 0.8, (0, 0, 255), 2)
    cv2.rectangle(image, (710, 390), (1210, 690), (0, 255, 0), 4)  # 绿色框
    cv2.arrowedLine(image, (0, 0), (400, 0), (0, 255, 255), 8)     # +X
    cv2.arrowedLine(image, (0, 0), (0, 400), (0, 255, 255), 8)     # +Y

    cv2.imshow("Image Pixels and Drawing - Press Any Key", image)
    cv2.waitKey(0)
    cv2.destroyAllWindows()


if __name__ == "__main__":
    main()
```

**3. 运行后按任意键关闭窗口**

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `POINT_X` / `POINT_Y` | int | 需在图像范围内 | X 是列、Y 是行 |
| `image[Y, X]` | numpy | — | 顺序不能反，反了读错位置 |
| 颜色元组 | tuple | `(B, G, R)` | 0～255，红是 `(0,0,255)` |
| 线宽 `-1` | int | — | 只对 `circle`/`rectangle` 表示填充 |
| `waitKey(0)` | int | 0 | 0 表示无限等待按键 |

## 预期效果与排查

打印尺寸（如 `1280 × 720`）与某点 BGR；窗口里能看到红点、绿框和左上角的黄色坐标轴。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `IndexError` | 坐标超出图像范围 | 先打印 `width/height` 再取点 |
| 颜色画反（红出蓝） | 用了 RGB 顺序 | OpenCV 一律 BGR |
| 中文路径读不到图 | `cv2.imread` 不支持中文 | 用 `np.fromfile + imdecode` |
