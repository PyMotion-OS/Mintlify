## 前置条件

- `pip install opencv-python numpy`
- 已知摄像头 RTSP 地址，例如 `rtsp://192.168.43.226:554/11`（手机 IP 摄像头 App 会给）
- 手机/摄像头与电脑同一 Wi-Fi

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `class Camera` | 把连接、取图、释放封装成类，`with Camera(url) as camera` 进入连接、退出释放 |
| `Camera.__enter__()` | `with` 进入时连接摄像头；`isOpened()` 检查是否真连上 |
| `Camera.get_image()` | `read()` 取一帧，返回 BGR 图片 |
| `log_message(level, source, message)` | 统一日志：时间、级别、来源、说明 |
| `save_image(path, image)` | `imencode` 编码后写文件，中文路径兼容 |

level 表示 INFO 或 ERROR 等级别，source 表示日志来源，message 表示具体说明\n    current_time = datetime.now()                           # now() 取得电脑当前的日期和时间\n\n    # strftime() 把时间转成文字；%Y、%m、%d、%H、%M、%S、%f 分别表示年、月、日、时、分、秒和微秒\n    time_text = current_time.strftime("%Y-%m-%d %H:%M:%S.%f")\n    time_text = time_text[:-3]                              # 创建 output 文件夹，已经存在时不报错\n    is_encoded, image_bytes = cv2.imencode(path.suffix, image)  # 按 .jpg 后缀把 BGR 图片编码成文件字节\n    if not is_encoded:                                      # 编码失败时不继续写入文件\n        raise ValueError("摄像头图片编码失败")\n    path.write_bytes(image_bytes.tobytes())                 # 把编码后的字节写入 camera_image.jpg\n\nclass Camera:\n    """把摄像头的连接、取图和释放操作放在一个类里。\n\n    self 表示当前这个 Camera 对象，可以保存这个摄像头的地址和连接。\n    使用 with Camera(...) as camera 时，进入 with 会连接，离开 with 会自动释放。\n    """\n\n    def __init__(self, camera_url):\n        """创建 Camera 对象时保存地址，此时还没有连接摄像头。"""\n        self.camera_url = camera_url                        # 把传入的摄像头地址保存在当前对象中\n        self.capture = None                                 # 预留保存摄像头连接的位置\n\n    def __enter__(self):\n        """进入 with 时自动执行，连接摄像头并返回当前对象。"""\n        if not self.camera_url:\n            raise ValueError("请先填写 CAMERA_URL")\n\n        # VideoCapture() 创建视频获取对象，并尝试打开传入的 RTSP 摄像头地址\n        # 返回的对象保存在 self.capture，后面才能继续检查、取图和释放\n        self.capture = cv2.VideoCapture(self.camera_url)\n        if not self.capture.isOpened():                     # 检查连接是否真正打开\n            raise ValueError("摄像头连接失败，请检查地址和网络")\n        return self                                         # as camera 得到的就是当前 Camera 对象\n\n    def get_image(self):\n        """取得一张图片。"""\n        # read() 请求一帧画面，同时返回取图结果 is_received 和 BGR 图片 image\n        is_received, image = self.capture.read()\n        if not is_received:                                 # 没有得到图片时中断本次运行\n            raise ValueError("没有取得摄像头图片")\n        return image                                        # 把图片交给调用 get_image() 的代码\n\n    def __exit__(self, exc_type, exc_value, traceback):\n        """成功进入 with 后，结束或中途出错都会自动执行并释放摄像头。\n\n        exc_type、exc_value 和 traceback 是 Python 自动传入的出错信息，本例程不需要使用。\n        """\n        self.capture.release()                              # release() 关闭连接并释放摄像头资源\n\ndef main():\n    """取得、保存并显示一张摄像头图片。"""\n    try:\n        # 进入 with 会自动调用 __enter__()，离开 with 会自动调用 __exit__()\n        with Camera(CAMERA_URL) as camera:\n            log_message("INFO", "camera", "摄像头已连接")\n            image = camera.get_image()\n\n        # with 结束后摄像头已经释放，但取得的 image 仍然可以保存和显示\n        save_image(OUTPUT_PATH, image)\n        log_message("INFO", "camera", f"图片已保存: {OUTPUT_PATH}")\n\n        # imshow() 打开窗口显示图片；第一个参数是窗口标题，第二个参数是要显示的 image\n        cv2.imshow("Camera image - press any key to close", image)\n        cv2.waitKey(0)                                      # waitKey(0) 会一直等待，直到使用者按下任意键\n        cv2.destroyAllWindows()                             # 关闭 OpenCV 创建的所有图片窗口\n    except ValueError as exc:\n        log_message("ERROR", "camera", str(exc))            # str() 把出错对象 exc 转成可以作为日志消息显示的文字\n\nif __name__ == "__main__":\n    main()'}

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `CAMERA_URL` | str | `rtsp://...` | RTSP 摄像头地址，改成你自己的 |
| `OUTPUT_PATH` | Path | `output/camera_image.jpg` | 保存位置，自动建 `output` 目录 |
| `__enter__` / `__exit__` | 方法 | — | `with` 进入连接、退出释放 |
