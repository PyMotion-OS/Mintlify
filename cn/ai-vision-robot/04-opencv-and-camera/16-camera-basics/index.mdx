## 本页目标

封装一个 `Camera` 类：`with Camera(url)` 进入时连接、退出时释放；`get_image()` 取一帧。取到的图既保存到 `output/camera_image.jpg`，也弹窗显示。这是后面所有视觉例程的取图入口。

## 前置条件

- `pip install opencv-python numpy`
- 已知摄像头 RTSP 地址，例如 `rtsp://192.168.43.226:554/11`（手机 IP 摄像头 App 会给）
- 手机/摄像头与电脑同一 Wi-Fi

## 动手步骤

**1. 新建 `16_camera_basics.py`，把 `CAMERA_URL` 改成本机摄像头地址**

**2. 写入核心代码**

```python
from pathlib import Path
import cv2

CAMERA_URL = "rtsp://192.168.43.226:554/11"     # 改成你的
BASE_DIR = Path(__file__).parent
OUTPUT_PATH = BASE_DIR / "output/camera_image.jpg"


def save_image(path, image):
    path.parent.mkdir(exist_ok=True)
    ok, image_bytes = cv2.imencode(path.suffix, image)
    if not ok:
        raise ValueError("摄像头图片编码失败")
    path.write_bytes(image_bytes.tobytes())


class Camera:
    def __init__(self, camera_url):
        self.camera_url = camera_url
        self.capture = None

    def __enter__(self):
        if not self.camera_url:
            raise ValueError("请先填写 CAMERA_URL")
        self.capture = cv2.VideoCapture(self.camera_url)
        if not self.capture.isOpened():
            raise ValueError("摄像头连接失败，请检查地址和网络")
        return self

    def get_image(self):
        ok, image = self.capture.read()
        if not ok:
            raise ValueError("没有取得摄像头图片")
        return image

    def __exit__(self, *exc_info):
        self.capture.release()


def main():
    with Camera(CAMERA_URL) as camera:
        image = camera.get_image()
    save_image(OUTPUT_PATH, image)          # with 已退出，图仍在内存里
    cv2.imshow("Camera image - press any key to close", image)
    cv2.waitKey(0)
    cv2.destroyAllWindows()


if __name__ == "__main__":
    main()
```

**3. 运行**

```bash
python 16_camera_basics.py
```

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `CAMERA_URL` | str | RTSP 地址 | 必须带 `rtsp://`，路径因 App 而异 |
| `capture.read()` | 返回 | `(ok, image)` | `ok=False` 表示这一帧失败，可重试 |
| `image` | numpy BGR | H×W×3 | 通道顺序是 BGR，不是 RGB |
| `cv2.imencode(后缀, 图)` | — | 返回 `(ok, bytes)` | 中文路径就用这种写法，别用 `imwrite` |

## 预期效果与排查

弹窗显示摄像头画面，同时当前目录多出 `output/camera_image.jpg`。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `摄像头连接失败` | 地址错、不同网段、端口不是 554 | 用 VLC 先试同一地址能否播 |
| 取图卡住 1～2 秒 | RTSP 建链慢 | 正常，首帧总是慢 |
| 保存的图是黑的 | 摄像头夜间模式或曝光未就绪 | 连续取几帧丢弃前两帧 |
| `imencode` 报错 | 后缀不是 `.jpg`/`.png` | 检查 `OUTPUT_PATH` |
