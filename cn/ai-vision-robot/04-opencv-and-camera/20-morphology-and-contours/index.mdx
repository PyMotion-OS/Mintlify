## 本页目标

掩膜里总有小噪点、也有被切碎的缺口。本页用**开运算**去噪、**闭运算**补洞，再用 `findContours()` 取轮廓、按面积过滤。跑完你会得到一张"只圈出真正目标"的图。

## 前置条件

- 同目录有 `camera_frame.jpg` 和例程 19 留下的 `target_mask.py`
- 完成 4.4

## 动手步骤

**1. 新建 `20_morphology_and_contours.py`**，先确认 `target_mask.py` 里的 `make_target_mask(image, target_type)` 可被导入（例程 19 若已写成函数，直接复用）

**2. 写入核心代码**

```python
import numpy as np
import cv2
from pathlib import Path
from target_mask import make_target_mask

TARGET_TYPE = "blue"     # gray / blue / green / yellow
KERNEL_SIZE = 3          # 形态学核边长（像素）
MIN_AREA = 500           # 有效轮廓最小面积

BASE_DIR = Path(__file__).parent
IMAGE_PATH = BASE_DIR / "camera_frame.jpg"


def load_image():
    return cv2.imdecode(np.fromfile(IMAGE_PATH, dtype=np.uint8), cv2.IMREAD_COLOR)


def main():
    image = load_image()
    target_mask = make_target_mask(image, TARGET_TYPE)

    kernel = np.ones((KERNEL_SIZE, KERNEL_SIZE), np.uint8)
    opened_mask = cv2.morphologyEx(target_mask, cv2.MORPH_OPEN, kernel)    # 先腐蚀去小噪点，再膨胀复原
    closed_mask = cv2.morphologyEx(opened_mask, cv2.MORPH_CLOSE, kernel)   # 先膨胀补缺口，再腐蚀复原

    contours, _ = cv2.findContours(closed_mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    valid_contours = [c for c in contours if cv2.contourArea(c) >= MIN_AREA]

    contour_image = cv2.cvtColor(closed_mask, cv2.COLOR_GRAY2BGR)
    cv2.drawContours(contour_image, valid_contours, -1, (0, 140, 255), 4)

    print(f"全部轮廓: {len(contours)}")
    print(f"有效轮廓: {len(valid_contours)}")

    cv2.imshow("1 - Target Mask", target_mask)
    cv2.imshow("2 - After Opening", opened_mask)
    cv2.imshow("3 - After Closing", closed_mask)
    cv2.imshow("4 - Valid Contours", contour_image)
    cv2.waitKey(0)
    cv2.destroyAllWindows()


if __name__ == "__main__":
    main()
```

**3. 运行，对比四个窗口**

`全部轮廓` 通常远大于 `有效轮廓` —— 差出来的就是被面积过滤掉的噪点。

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `TARGET_TYPE` | str | `"blue"` | 传给 `make_target_mask`，决定用灰度还是某个 HSV 颜色 |
| `KERNEL_SIZE` | int | 3～7（奇数） | 核越大清理越狠，目标小的时候会把它一起啃掉 |
| `MIN_AREA` | int | 100～2000 | 太小噪点全进来，太大会漏掉远处目标 |
| `cv2.MORPH_OPEN` | 常量 | — | 腐蚀→膨胀，去孤立白点 |
| `cv2.MORPH_CLOSE` | 常量 | — | 膨胀→腐蚀，补目标内部的黑洞和小缺口 |

## 预期效果与排查

掩膜上零散白点消失、目标内部变实，最后一张图只有目标被橘色轮廓框住。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 目标被啃掉一半 | `KERNEL_SIZE` 太大 | 降到 3 |
| 噪点还在 | 掩膜本身选得太宽 | 回 4.4 收紧 S/V 下限，形态学不负责救掩膜 |
| `有效轮廓: 0` | `MIN_AREA` 大于目标实际面积 | 打印 `cv2.contourArea()` 的实际值再定阈值 |
| 一个目标出两个轮廓 | 中间被切断 | 增大 `KERNEL_SIZE` 做闭运算，或降低掩膜下限 |
