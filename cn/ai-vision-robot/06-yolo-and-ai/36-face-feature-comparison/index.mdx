## 前置条件

- 把 `common/face_recognition_sface_2021dec.onnx` 和两张肖像 `face_sample.png`、`face_sample_2.png` 放到本页 data 目录

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `cv2.FaceRecognizerSF.create(...)` | OpenCV 自带 SFace 特征模型入口 |
| `recognizer.alignCrop(image, raw_face)` | 按五个关键点摆正并裁剪人脸 |
| `recognizer.feature(aligned_face)` | 提取一行 128 个特征数值 |
| `recognizer.match(...)` | 余弦相似度比较两组特征 |

## 完整示例

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `MATCH_THRESHOLD` | float | 0.50 | 达到此值判为同一个人 |
| `PERSON_NAME` | str | `user01` | 人为设置的登记代号 |
| 相似度 | float | 0~1 | 越大越像，但不是概率 |

> 本页产出 `create_face_recognizer` / `get_face_feature` / `compare_face_features` / `save_feature_file`，6.7 吸收。
