## 本页目标

从"有没有脸"到"**是谁的脸**"。流程三步：YuNet 找到脸 → SFace 根据五个关键点对齐并裁剪 → 提 128 个特征 → 两两算余弦相似度。相似度 ≥ 阈值就判同一个人。

## 前置条件

- `common/` 下有 `face_recognition_sface_2021dec.onnx`
- 同目录 `data/` 下有 `face_sample.png`（登记）和 `face_sample_2.png`（查询），两张**必须同一人**
- 完成 6.5

## 动手步骤

**1. 在 `face_tools.py` 里补 `get_quality_face()`**

```python
def get_quality_face(detector, image):
    """检测 + 质量判断，返回 SFace 需要的一行 YuNet 原始数据（含 5 个关键点）。"""
    image_height, image_width = image.shape[0], image.shape[1]
    detector.setInputSize((image_width, image_height))
    raw_faces = detector.detect(image)[1]
    if raw_faces is None or len(raw_faces) != 1:
        raise ValueError("图片中必须恰好有一张人脸")

    raw_face = raw_faces[0]
    face = {"box": [round(raw_face[0]), round(raw_face[1]),
                    round(raw_face[2]), round(raw_face[3])]}
    is_good, reason = check_face_quality(image, face)
    if not is_good:
        raise ValueError(reason)
    return raw_face          # 注意：返回原始行，不是整理后的 dict
```

**2. 新建 `35_face_feature_comparison.py`**

```python
from pathlib import Path
import cv2
import numpy as np
from face_tools import create_face_detector, get_quality_face, load_image

MATCH_THRESHOLD = 0.50        # 余弦相似度达到它判为同一人
PERSON_NAME = "user01"        # 人为设定的登记代号，不是模型"猜"出来的名字

COMMON_DIR = Path(__file__).parents[1] / "common"
RECOGNITION_MODEL = COMMON_DIR / "face_recognition_sface_2021dec.onnx"
DATA_DIR = Path(__file__).with_name("data")
FEATURE_FILE = DATA_DIR / "faces.npz"


def create_face_recognizer():
    model_bytes = np.fromfile(RECOGNITION_MODEL, dtype=np.uint8)
    return cv2.FaceRecognizerSF.create("onnx", model_bytes, np.empty(0, np.uint8))


def get_face_feature(detector, recognizer, image):
    raw_face = get_quality_face(detector, image)
    aligned_face = recognizer.alignCrop(image, raw_face)   # 按 5 个关键点摆正并裁剪
    feature_row = recognizer.feature(aligned_face)         # 输出 1×128
    return feature_row.reshape(-1)                         # 拉平成一维 128 个数


def compare_face_features(recognizer, reference_feature, query_feature):
    # FR_COSINE 是余弦相似度，越大越像；不是概率
    score = recognizer.match(reference_feature, query_feature,
                             cv2.FaceRecognizerSF_FR_COSINE)
    return float(score)


def save_feature_file(names, features):
    FEATURE_FILE.parent.mkdir(exist_ok=True)
    feature_rows = np.asarray(features, dtype=np.float32).reshape(-1, 128)
    np.savez(FEATURE_FILE, names=np.asarray(names, dtype=str), features=feature_rows)


def main():
    detector = create_face_detector()
    recognizer = create_face_recognizer()

    reference_image, query_image = load_image()
    reference_feature = get_face_feature(detector, recognizer, reference_image)
    query_feature = get_face_feature(detector, recognizer, query_image)

    score = compare_face_features(recognizer, reference_feature, query_feature)
    print(f"特征数量: {reference_feature.size}")
    print(f"余弦相似度: {score:.3f}")
    print("匹配结果:", "同一个人" if score >= MATCH_THRESHOLD else "不匹配")

    # 只登记参考图；查询图用来检验，绝不混进登记库
    save_feature_file([PERSON_NAME], [reference_feature])
    print(f"登记代号: {PERSON_NAME}\n特征文件: {FEATURE_FILE}")


if __name__ == "__main__":
    main()
```

**3. 运行，记下相似度数值**

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `MATCH_THRESHOLD` | float | 0.3～0.6 | OpenCV 官方推荐 0.363。**0.50 偏严格**，误拒多、误认少 |
| `FR_COSINE` | 常量 | — | 余弦相似度，官方另一选项 `FR_NORM_L2`（L2 距离，越小越像） |
| 特征维度 | int | 128 | SFace 固定输出，存库时按 `reshape(-1, 128)` |
| `PERSON_NAME` | str | 自定义 | 只是标签，模型不做身份判断 |

## 数据结构

`get_face_feature()` → `np.ndarray`，形状 `(128,)`，`float32`：

```python
array([ 0.031, -0.118,  0.207, ...,  0.044], dtype=float32)   # 共 128 个
```

`FEATURE_FILE`（`faces.npz`）内容：

```python
{
    "names": array(["user01"], dtype="<U6"),        # 形状 (N,)
    "features": array(..., dtype=float32),          # 形状 (N, 128)
}
```

**NPZ 里没有原始照片**，只有数值特征 —— 这点在隐私上是重要的。

## 预期效果与排查

同一人的两张照片相似度通常 0.6～0.9；不同人通常 0.0～0.3。终端打印 `同一个人` 并生成 `data/faces.npz`。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 同一人也只有 0.3 | 阈值 0.50 太严 / 两张角度光照差太大 | 降到 0.363（官方值）再试 |
| 不同人也 0.7 | 拿同一个人的两张图当"查询"了 | 换成另一个人重试 |
| 报"必须恰好有一张人脸" | 图里没人、有两人、或质量不合格 | 用 6.5 的检查先过一遍 |
| 相似度是 `nan` | 特征含 NaN，常见于对齐失败 | 确认 `raw_face` 是原始 15 数行，不是整理后的 dict |
