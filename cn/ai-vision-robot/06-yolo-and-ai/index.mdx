# 6 YOLO 与 AI

## 模块目标

这是全课程最长的一段，三条主线并行推进：

1. **通用目标检测**（YOLO）：先把图里的物体框出来，再让框跨帧跟着同一物体走
2. **人脸链路**（检测 → 质量 → 特征 → 录入 → 识别 → 交互）：一套完整的人脸应用
3. **视觉跟随**（选主目标 → 居中 → 控距 → 观测）：把检测结果变成底盘动作

## 例程顺序

| 例程 | 内容 | 关键点 |
| --- | --- | --- |
| 6.1 YOLO 图片检测 | 单张图检测并画框 | `YOLO_OFFLINE` 必须在 import 前设置 |
| 6.2 YOLO 实时检测 | 摄像头逐帧检测 | 抽帧检测 + 缓存结果，不每帧都跑模型 |
| 6.3 目标跟踪 | 给检测框分配 ID，跨帧保持同一目标 | 按 IoU 关联，丢失后保留若干帧 |
| 6.4 人脸检测 | 独立的人脸检测器 | 比通用 YOLO 更轻，先跑通这条链路 |
| 6.5 人脸质量评估 | 判断这张脸能不能用 | 模糊度、亮度、角度、尺寸四维打分 |
| 6.6 人脸特征比对 | 两张脸是不是同一个人 | 特征向量余弦相似度 + 阈值 |
| 6.7 人脸录入与识别 | 建库 → 识别 | 阈值松会认错人，紧则认不出 |
| 6.8 人脸问候项目 | 认出人 → 舵机转向 + 打招呼 | 把前面五步合成可演示项目 |
| 6.9 主目标选择 | 画面里多人多物时选谁 | 面积优先 + 中心优先 + 切换滞后 |
| 6.10 YOLO 目标居中 | 目标框居中 | 与 5.4 同一套偏差算法，换检测源 |
| 6.11 跟随距离策略 | 远了追、近了停 | 用 `area_ratio` 估距离，不是真实米数 |
| 6.12 跟随观测 | 输出完整跟随状态 | 一页看全：目标、偏差、距离档、动作 |

## 三个高频坑

> - `YOLO_OFFLINE = "1"` 必须在 `import ultralytics` **之前**设置，否则启动时联网拉权重会卡住
> - 帧去重：用 `last_image` 判断是否新帧，否则同一个框被重复累计，角度会一路累加跑飞
> - `valid_for` 必须大于循环周期，否则指令还没执行就过期，表现为"车一顿一顿"
