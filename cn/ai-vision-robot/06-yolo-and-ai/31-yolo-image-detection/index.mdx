## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `os.environ["YOLO_OFFLINE"] = "true"` | 必须在 `import ultralytics` 之前设置，否则联网拉权重 |
| `load_yolo_resources()` | 读标签表和本地模型，返回 `labels` 和 `model` |
| `model.predict(...)` | 执行检测，返回 `Results`，张量需 `cpu().tolist()` |
| `detect_objects(...)` | 把模型输出整理成 `class_id/label/confidence/box` 四个稳定字段 |

### 运行方式

```bash
python 31_yolo_image_detection.py
```

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `CONFIDENCE` | float | 0.25 | 只保留置信度达标的检测结果 |
| `image_size` | int | 640 | 模型输入尺寸，越大细节越多、越慢 |
| `device` | str | `"cpu"` | 电脑和树莓派都能运行的设备选择 |

> 本页产出 `yolo_detection.py`（`load_yolo_resources`、`detect_objects`、`draw_detections`）。

## 本页产出 · yolo_detection.py

本页把三个 YOLO 函数整理成一个可复用文件：`load_yolo_resources()` 读本地标签表和模型，`detect_objects()` 把模型输出整理成 `class_id` / `label` / `confidence` / `box` 四个稳定字段（含处理毫秒数），`draw_detections()` 画出类别、置信度、检测框和耗时。不含 `main`、不取图，供实时检测、跟踪和跟随的页面直接 import。
