**2. 新建 `41_following_observation.py`**

```python
import cv2
from camera import Camera, log_message
from target_selection import choose_follow_motion, find_unique_target
from yolo_detection import draw_follow_tracking, load_yolo_resources, track_objects

CONFIDENCE = 0.25
W = 90


def choose_target(tracks, selected_id, target_label):
    """首次只在唯一时锁定编号；之后只认这个编号，不换人。"""
    candidates = [t for t in tracks if t["label"] == target_label]

    if selected_id is None and len(candidates) == 1:      # 关键改动：6.3 选最大，这里要求唯一
        selected_id = candidates[0]["track_id"]

    for candidate in candidates:
        if candidate["track_id"] == selected_id:
            return candidate, selected_id                  # 锁定的人还在，继续跟

    return None, selected_id                               # 人不在：保留编号，本帧无目标


def main():
    try:
        _, model = load_yolo_resources()
        selected_id, last_image = None, None
        with Camera() as camera:
            while True:
                key = cv2.waitKey(100)
                if key == 27:
                    break
                if key == ord("r"):
                    selected_id = None                      # R 清空编号，等下一个唯一目标

                image = camera.latest()
                if image is None or image is last_image:
                    continue                                # 断流时保留编号，不清空
                last_image = image

                tracks, _ = track_objects(model, image, CONFIDENCE)
                target, selected_id = choose_target(tracks, selected_id, "person")

                if target is None:
                    target_data = find_unique_target([], image.shape, "person")
                else:
                    target_data = find_unique_target([target], image.shape, "person")

                v, w, state = choose_follow_motion(
                    target_data["error_x"], target_data["area_ratio"], W)

                cv2.imshow("Following observation - R select, Esc close",
                           draw_follow_tracking(image, target_data, selected_id, v, w, state))
    except KeyboardInterrupt:
        log_message("INFO", "follow", "Ctrl+C 主动结束")
    except (OSError, ValueError, cv2.error) as exc:
        log_message("ERROR", "follow", str(exc))
    finally:
        cv2.destroyAllWindows()


if __name__ == "__main__":
    main()
```

**3. 运行：一个人站着按 `R` 锁定 → 第二个人进来观察是否换人 → 第二个人走开按 `R` 重选**

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `R` 键 | 键值 `ord("r")` | — | 手动重选，把 `selected_id` 置 `None` |
| 锁定条件 | 判定 | `len(candidates) == 1` | 画面必须**只有一个人**才能锁定 |
| `W` | float | 60～120 °/s | 原地转向速度 |
| 断流行为 | — | 保留 `selected_id` | 短暂丢流不该导致重新选人 |

## 三次演化对比

| 例程 | 首次选谁 | 之后 | 多人时 |
| --- | --- | --- | --- |
| 6.3 | 面积最大的 | 只认这个 ID | 照样有目标（可能选错） |
| 6.9 | 不选 | — | `ambiguous`，不动 |
| **6.12** | **只在唯一时锁定** | **只认这个 ID，不换人** | **已锁定则继续跟锁定的人；未锁定则不动** |

6.12 把两者的优点合并了：锁定前严格（不猜），锁定后专一（不换）。

## 状态流

```
未锁定 ──画面里恰好 1 人──▶ 锁定 ID=3，开始跟随
   ▲                              │
   │                        ID=3 消失
   │                              ▼
   └──── 按 R 重新选择 ◀──── 归零 (0,0,lost)，保留 ID=3
```

注意"保留 ID=3"：人短暂被遮挡后重新出现，编号若还是 3 会自动续上，不需要按 R。

## 预期效果与排查

窗口显示目标框、`ID 3`、`V/W/state`。第二个人进来不影响锁定；第一个人走开 → `V=0 W=0 state=lost`；按 `R` 可重新锁定。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 两个人在场一直锁不上 | 锁定要求唯一，这是设计 | 让其他人在锁定时走开，或按 `R` 重试 |
| 人走开后立刻跟了别人 | `selected_id` 被重置 | 检查缺失分支是否返回了原 `selected_id` |
| 按 `R` 没反应 | `waitKey` 在 `continue` 之后 | 键检测必须在取图之前 |
| 目标框有但 `V=0` | 最近距离档 | 人退后，或调 `area_ratio` 阈值 |
| 画面卡顿 | 跟踪 + 检测双开销 | 保持 `imgsz=320`，必要时降 `CONFIDENCE` |
