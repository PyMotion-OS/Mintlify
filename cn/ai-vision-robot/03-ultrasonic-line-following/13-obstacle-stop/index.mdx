## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `STOP_DISTANCE` | int | 350 毫米 | 小于等于它就停机 |
| `SLOW_DISTANCE` | int | 500 毫米 | 进入该距离开始减速 |
| `NORMAL_RPM` / `SLOW_RPM` | int | 30 / 15 | 两档速度 |
| `state` | str | `no_echo` / `valid` | `no_echo` 视为未测到障碍 |
| `frequency` | str | `"high"` | 超声波读得更勤 |
| `data_queue_size` | int | 1 | 队列只留最新一条，不堆旧数据 |

> 分档边界：`< 350` 停、`350～500` 减速、`> 500` 全速；无回波不算障碍，但无效读数必须停。

## 本页产出 · obstacle_policy.py

本页把避障策略整理成一个可复用文件：包含 `ultrasonic_to_vw()` 一个函数——输入超声波数据和循迹算出的 V/W，输出避障后的 V/W 和状态（`stop` / `slow` / `normal` / `clear`）。不含 `main`、不连设备，只有分档判断逻辑，供需要避障的页面直接 import。策略文件的分档边界（`STOP_DISTANCE` 100 毫米 / `SLOW_DISTANCE` 300 毫米）比本页演示脚本（350/500）更保守，3.5 与 7.1 都用它。
