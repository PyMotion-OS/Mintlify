## 模块目标

把「能感知」变成「能应对」。先用超声波学会避障和停车，再用五路循迹传感器学会跟着线走，最后把两者叠加成「安全循迹」——既跟着线，又躲得开障碍。

完成本模块后，你可以做到——

- 用超声波距离分档，让车看到障碍自动减速、停下（**避障**）
- 用线程和指令有效期，保证任何情况下都能把车停住（**安全停车**）
- 把五路循迹的 `True/False` 分类成图案、算出偏差（**循迹感知**）
- 用比例控制把偏差转成双轮转速，真正跟着线走（**循迹控制**）
- 把避障和循迹串起来，丢线即停、遇障即躲（**安全循迹**）

## 例程顺序

| 例程 | 内容 | 关键点 |
| --- | --- | --- |
| 3.1 避障停车 | 超声波距离分档 | 远全速、近减速、太近停，断流也停 |
| 3.2 安全停车 | 线程 + 指令有效期 | 输入 stop / 超时 / Ctrl+C / 断网都能停 |
| 3.3 循迹分类与运动计算 | 五路 → 图案分类 + V/W | 质心法算偏差、比例控制 |
| 3.4 循迹控制 | 接上实时数据真正跑起来 | `medium` 频率 + 0.35 秒有效期 |
| 3.5 安全循迹 | 循迹 + 避障叠加 | 两个策略函数串起来，丢线即停 |

## 关键概念

| 概念 | 含义 |
| --- | --- |
| 距离分档 | 无回波不算障碍、无效必须停，`<350` 停、`350~500` 减速、`>500` 全速 |
| 图案分类 | `line` 正常单段线、`lost` 丢线、`wide` 线太宽、`multiple` 多段 |
| 偏差 `line_offset` | 触发探头的平均位置，负=线偏左，正=线偏右 |
| 增益 `K` | 每单位偏差增加多少 °/s 的 W，太大画龙、太小拐不过弯 |

> 地面光线、轮胎打滑都会影响效果。先在直线上把 `K` 调到不抖，再上弯道。
