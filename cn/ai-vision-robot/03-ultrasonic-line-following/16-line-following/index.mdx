## 前置条件

- Robot 通信正常（参考 [1.1 WIFI模式连接](../../01-python-basics/01-connect-wifi/index)，能打印出设备 ID）
- 把 3.3 的产出 `line_control.py`、2.4 的产出 `differential_drive.py` 复制到本页目录
- 赛道：黑线宽 20 mm、转弯半径 ≥ 150 mm

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `from line_control import PATTERN_NAMES, line_tracker_to_vw` | 直接用 3.3 的分类与偏差，不重写 |
| `drive(commands, v, w)` | 2.4 产出的差速封装：算左右轮转速并发送双轮目标 |
| `data_queue.read(timeout=1.0)` | 断流时返回 `None`，V/W 归零；循环节奏由它控制，不用 sleep |

### 运行方式

```bash
python line_following.py
```

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `V` | int | 80 毫米/秒 | 基础前进速度，太快会冲出弯道 |
| `K` | int | 25 | 转弯增益，先 15 试，画龙再加 |
| `valid_for` | float | 0.35 秒（`drive` 默认） | 每轮循环都会重发，断流后 0.35 秒自动停 |
