## 前置条件

- Robot 通信正常（参考 [1.1 WIFI模式连接](../../01-python-basics/01-connect-wifi/index)，能打印出设备 ID）
- 把 3.1 的产出 `line_control.py`、2.4 的产出 `differential_drive.py` 复制到本页目录
- 赛道：黑线宽 20 mm、转弯半径 ≥ 150 mm

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `from line_control import PATTERN_NAMES, line_tracker_to_vw` | 直接用 3.1 的分类与偏差，不重写 |
| `run(data_queue, commands)` | 主循环：读五路 → 算 V/W → 差速转 RPM → 发双轮 |
| `data_queue.read(timeout=1.0)` | 断流时返回 `None`，V/W 归零 |
| `frequency="medium"` | 约 10 Hz 更新五路，够循迹且不压网络 |

first_position + 1   # 两端之间连续排列时应有的位置数量\n\n    if continuous_count != detected_count:                  # 数量不同表示中间存在未探测位置\n        return "multiple", None\n    if detected_count > MAX_LINE_SENSORS:                   # 连续触发数量超过正常线宽\n        return "wide", None\n\n    # 第四步：用平均值求线的中心位置（质心法），单位是一个探头间距\n    # 偏差为负表示线在左边，0 表示居中，正数表示线在右边；下一步用它计算 W\n    line_offset = sum(detected_positions) / detected_count  # sum() 求和，再除以数量得到中心位置\n    return "line", line_offset                              # 返回单段连续线和中心偏差\n\n\ndef line_tracker_to_vw(sensor_states, v, k):\n    """传入五路状态、基础 V 和增益 K，返回 V、W 和图案分类。"""\n    # 调用上面的分类函数，得到图案分类和循迹线偏差\n    pattern_type, line_offset = classify_pattern(sensor_states)  # sensor_states 是五路 True/False 状态\n    if pattern_type != "line":                              # 只有单段连续线能够确定转弯方向\n        return 0, 0, pattern_type                           # 其他图案返回 V=0、W=0\n\n    # 使用比例控制计算 W，循迹线偏得越多，机器人转得越快\n    w = k * (0 - line_offset)                               # 0 减偏差改变方向：负偏差得到正 W 左转\n    return v, w, pattern_type                               # 返回基础 V、计算后的 W 和图案分类'}

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `V` | int | 80 毫米/秒 | 基础前进速度，太快会冲出弯道 |
| `K` | int | 25 | 转弯增益，先 15 试，画龙再加 |
| `frequency` | str | `medium` | 约 10 Hz；`high` 更跟手但网络压力大 |
| `data_queue_size` | int | 1 | 只要最新帧，避免用旧数据修正 |
| `valid_for` | float | 0.35 秒 | 大于 `read` 等待时间，断流先自动停 |
