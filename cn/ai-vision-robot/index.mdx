## 手册讲什么

这套手册按"一台车从零到能看能动"的顺序编排，八个模块是一条链：

1. **Robot 与 Python 基础**：连上设备，会写最基本的控制代码
2. **实时运动控制**：电机、舵机、差速、键盘遥控
3. **超声波与循迹**：能停、会循线、两者叠加成安全循迹
4. **OpenCV 与摄像头**：取帧、掩膜、轮廓，认出颜色目标
5. **视觉控制**：舵机跟踪、二维码定位
6. **YOLO 与 AI**：目标检测、人脸链路、视觉跟随
7. **综合项目**：把传感器、循迹、视觉、舵机装成一个能演示的项目
8. **树莓派部署**：把 PC 上跑通的代码搬上车，压性能

## 怎么用

- 每个页面固定四段：前置条件 → 关键函数 → 完整示例（代码 / 结果预览 + 运行方式）→ 参数说明
- 代码块都可以展开、复制；较长的代码按住 Ctrl 滚动鼠标滚轮左右查看
- 模块内的页面有演化关系，建议按顺序完成；很多页面会直接 import 前面页面的产出文件
- 每页末尾会说明本页产出了哪个文件、哪些函数，供后面的页面复用

## 开始之前

- 一台 PyMotion 设备，能通过 WIFI 或 USB 连接
- Python 3.9 以上，能用 `pip` 装依赖
- 后续视觉模块需要一个 RTSP 摄像头（或用手机 IP 摄像头 App 代替）
