## 本页目标

一个机器人有两个传感器同时说话，听谁的？本页定一条**决策优先级**：丢线/等待 > 测距停机 > 减速 > 正常循迹。同时解决一个隐蔽的坑：**传感器事件会过期**，0.3 秒前的数据不能再当作现在的路况。

## 前置条件

- 完成 3.x（`line_tracker_to_vw`）、2.x（`vw_to_rpm`）、3.3（`obstacle_policy`）
- 同目录有 `differential_drive.py`、`line_control.py`、`obstacle_policy.py`

## 动手步骤

**1. 确认 `obstacle_policy.py` 里有分档函数**

```python
STOP_DISTANCE = 100     # ≤100 mm 停
SLOW_DISTANCE = 300     # 100～300 mm 减速


def ultrasonic_to_vw(ultrasonic_data, v, w):
    if ultrasonic_data.state == "no_echo":      # 无回波 = 前方空旷
        return v, w, "clear"
    if not ultrasonic_data.valid:
        return 0, 0, "invalid"
    if ultrasonic_data.distance <= STOP_DISTANCE:
        return 0, 0, "stop"
    if ultrasonic_data.distance < SLOW_DISTANCE:
        return v / 2, w / 2, "slow"              # 距离近时 V/W 同时减半
    return v, w, "normal"
```

**2. 新建 `42_sensor_decision.py`**

```python
import time
import pymotion as pm
from differential_drive import vw_to_rpm
from line_control import line_tracker_to_vw
from obstacle_policy import ultrasonic_to_vw

V = 60          # 循迹基础速度 mm/s
K = 25          # 每格偏差对应 °/s
TRANSPORT = "wifi"
TIMEOUT = 15.0

EVENT_MAX_AGE = 0.3      # 事件最大存活时间


def decide_motion(line_motion, ultrasonic_data):
    """先看循迹状态，再看测距，返回唯一允许执行的 V/W。"""
    v, w, line_state = line_motion
    if line_state != "line":
        return 0, 0, line_state              # 丢线/等待时，测距正常也不放行
    if ultrasonic_data is None:
        return 0, 0, "distance_waiting"      # 没测距数据就停
    return ultrasonic_to_vw(ultrasonic_data, v, w)


def run(data_queue, commands):
    tracker_event, ultrasonic_event = None, None
    next_send_at = time.monotonic()
    last_motion = None

    while True:
        # 第一步：按来源分别保存完整事件（不是只存 data）
        sensor_data = data_queue.read(timeout=0.5)
        if sensor_data is not None and sensor_data.source == "line_tracker":
            tracker_event = sensor_data
        elif sensor_data is not None and sensor_data.source == "ultrasonic":
            ultrasonic_event = sensor_data

        # 第二步：各自检查时效，过期就当没收到
        now = time.monotonic()
        line_motion = (0, 0, "line_waiting")
        if tracker_event is not None and now - tracker_event.received_monotonic <= EVENT_MAX_AGE:
            line_motion = line_tracker_to_vw(tracker_event.data.is_detected, V, K)

        ultrasonic_data = None
        if ultrasonic_event is not None and now - ultrasonic_event.received_monotonic <= EVENT_MAX_AGE:
            ultrasonic_data = ultrasonic_event.data

        # 第三步：合并决策
        v, w, reason = decide_motion(line_motion, ultrasonic_data)
        left_rpm, right_rpm = vw_to_rpm(v, w)

        # 第四步：0.1 秒节拍下发，停机也要显式发零速
        if now >= next_send_at:
            commands.motor_speeds.write({3: left_rpm, 4: right_rpm}, valid_for=0.35)
            next_send_at = now + 0.1

        motion = (reason, left_rpm, right_rpm)
        if motion != last_motion:
            print(f"策略: {reason}  V: {v} mm/s  W: {w} °/s  "
                  f"左轮: {left_rpm} RPM  右轮: {right_rpm} RPM")
            last_motion = motion


def main():
    try:
        with pm.lite.connect(transport=TRANSPORT, timeout=TIMEOUT) as robot:
            with robot.control():
                with robot.realtime.open(
                    data_sources=("line_tracker", "ultrasonic"),
                    command_targets={"motor_speeds": (3, 4)},
                    frequency="medium",
                    data_queue_size=8,
                ) as session:
                    run(session.data, session.commands)
    except KeyboardInterrupt:
        print("结果: Ctrl+C 主动停机")
    except (ValueError, pm.lite.LiteError) as exc:
        print(f"出错: {exc}")


if __name__ == "__main__":
    main()
```

**3. 运行：沿黑线走，前方伸手挡一下**

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `V` | int | 40～80 mm/s | 循迹基础速度 |
| `K` | float | 20～30 | 五路偏差 → 转向 |
| `EVENT_MAX_AGE` | float | 0.2～0.5 秒 | 超过这个时长的传感器事件直接丢弃 |
| `STOP_DISTANCE` | int | 80～150 mm | ≤ 它立即停 |
| `SLOW_DISTANCE` | int | 250～400 mm | 100～300 mm 区间 V/W 减半 |
| `data_queue_size` | int | 8 | 两种数据都进队列，不能设 1（会互相挤掉） |

## 决策优先级

```
line_state != "line"        ──▶ (0, 0, 丢线/等待)     最高优先
   │line
ultrasonic is None          ──▶ (0, 0, distance_waiting)
   │有测距
distance ≤ 100              ──▶ (0, 0, stop)
   │
distance < 300              ──▶ (V/2, W/2, slow)
   │
其它                        ──▶ (V, W, normal or clear)
```

**停机项永远排在前面**。如果反过来写（先判断能否前进，再考虑障碍），就会出现"明明前面有东西还在往前"。

## 为什么必须用 `received_monotonic`

| 写法 | 问题 |
| --- | --- |
| 只保存 `sensor_data.data` | 丢掉了"什么时候收到的"，无法判断新鲜度 |
| 用 `time.time()` | 系统校时会让时间跳变，可能算出负年龄 |
| 保存完整事件 + `received_monotonic` | 出队时刻 ≠ 采样时刻，决策用的是真实采样时间 |

数据从传感器到本机就有延迟，出队时"刚拿到"不代表"刚采样"。**必须用 SDK 记录的 `received_monotonic`**。

## 预期效果与排查

沿黑线稳定行驶；手伸到 30 cm 内速度减半；10 cm 内立即停；手拿开后自动恢复。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 一直 `line_waiting` | 没订阅 `line_tracker` | `data_sources` 里必须声明 |
| 一直 `distance_waiting` | 没订阅 `ultrasonic` | 同上 |
| 手伸过去不停 | 距离阈值太大 / 测距无效 | 打印 `ultrasonic_data` 看 `state` 和 `valid` |
| 两种数据互相覆盖 | `data_queue_size=1` | 改 8，按 `source` 分流 |
| 停车后没反应 | 停机分支没发零速 | `motor_speeds.write` 必须在节拍里统一执行 |
