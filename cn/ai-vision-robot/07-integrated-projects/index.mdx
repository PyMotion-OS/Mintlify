# 7 综合项目

## 模块目标

前面六个模块是零件，这个模块是装配。两个项目的共同点是：**都要做决策**——数据同时来自多个源（超声波、循迹、视觉），得先判断"该听谁的"，再决定动作。

## 例程顺序

| 例程 | 内容 | 关键点 |
| --- | --- | --- |
| 7.1 传感器决策 | 超声波 + 循迹同时看，决定直行/转向/停车 | 优先级：安全 > 循迹 > 视觉；`no_echo` 不能当 0 mm |
| 7.2 PC 视觉综合项目 | 循迹 + 颜色识别 + 舵机跟踪串成一条流程 | 状态机组织流程，不用层层 if 嵌套 |

## 决策优先级

> 多传感器冲突时的固定顺序：**安全层**（避障、急停）覆盖一切 → **循迹层**（保持在线）优先于视觉 → **视觉层**（目标交互）最后。写代码时按这个顺序逐层 return，比堆 `if/elif` 好读也好调。

## 前置

模块 2（运动与安全停车）、模块 3（循迹）、模块 5（舵机与视觉控制）全部跑通。
