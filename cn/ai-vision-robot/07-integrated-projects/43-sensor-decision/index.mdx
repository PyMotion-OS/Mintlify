## 前置条件

- Robot 通信正常（参考 [1.1 WIFI模式连接](../../01-python-basics/01-connect-wifi/index)，能打印出设备 ID）
- 把 `differential_drive.py`、`line_control.py`、`obstacle_policy.py` 复制到本页目录

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `decide_motion(line_motion, ultrasonic_data)` | 合并循迹意图和测距保护，返回唯一允许的 V/W |
| `line_tracker_to_vw(...)` | 3.3 产出，五路状态转循迹意图 |
| `ultrasonic_to_vw(...)` | 3.1 产出，按距离保持/减半/归零 V/W |

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `V` | int | 60 mm/s | 循迹基础前进速度 |
| `K` | int | 25 度/秒 | 每格五路偏差的转向增益 |
| `valid_for` | float | 0.35 秒 | 命令有效期，断流后自动失效 |

> 本页产出 `decide_motion()`。
