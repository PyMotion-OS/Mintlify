## 本页目标

YOLO 在树莓派上能不能用，取决于两个数：**单帧耗时**和**处理器温度**。本页把两者直接打在画面上。跑之前先明确预期：树莓派 4B 上 320 输入大约 200～500 ms/帧（2～5 FPS），**不是实时**，但足够做"每隔几帧看一次"的判断。

## 前置条件

- 完成 8.1（温度正常）、8.3
- 同目录有 `camera.py`、`yolo_detection.py`，`data/` 下有 `yolo11n.pt` 和 `coco_labels.json`
- 依赖已装在树莓派本地（`pip install ultralytics`）

## 动手步骤

**1. 新建 `48_measure_yolo.py`**

**2. 写入核心代码**

```python
from pathlib import Path
import cv2
from camera import Camera, log_message
from yolo_detection import detect_objects, draw_detections, load_yolo_resources

CONFIDENCE = 0.25
TEMP_WARN = 75.0


def run(camera, temperature):
    _, model = load_yolo_resources()          # 只加载一次
    last_image = None

    while True:
        if cv2.waitKey(20) == 27:
            return

        image = camera.latest()
        if image is None or image is last_image:
            continue                          # 只测新帧
        last_image = image

        detections, detection_time = detect_objects(model, image, CONFIDENCE)
        marked_image = draw_detections(image, detections, detection_time)

        temperature_text = "None"
        if temperature is not None:
            temperature_text = f"{temperature:.1f} C"
            if temperature >= TEMP_WARN:
                temperature_text += " HOT"

        cv2.putText(marked_image, f"TEMP {temperature_text}", (20, 70),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.75, (0, 176, 255), 2)
        cv2.imshow("YOLO performance - Esc to close", marked_image)


def main():
    try:
        temperature = None
        temperature_file = Path("/sys/class/thermal/thermal_zone0/temp")
        if temperature_file.exists():
            # 千分之一摄氏度 → ℃，启动时读一次
            temperature = int(temperature_file.read_text().strip()) / 1000

        with Camera() as camera:
            run(camera, temperature)
    except KeyboardInterrupt:
        log_message("INFO", "yolo", "Ctrl+C 主动结束")
    except (OSError, ValueError, cv2.error) as exc:
        log_message("ERROR", "yolo", str(exc))
    finally:
        cv2.destroyAllWindows()


if __name__ == "__main__":
    main()
```

**3. 运行 2～3 分钟，观察 `time=` 和 `TEMP` 的变化趋势**

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `CONFIDENCE` | float | 0.25 | 阈值，调高能减少后处理但省不了推理时间 |
| `IMAGE_SIZE` | int | 320（在 `yolo_detection.py` 里） | 树莓派上**必须 320**，640 会到 1 FPS 以下 |
| `TEMP_WARN` | float | 75 ℃ | 超过会降频，帧率进一步下降 |
| 温度读取时机 | — | 启动时一次 | 循环里反复读文件浪费 IO，也不准 |

## 参考数值

| 设备 | 输入 | 单帧耗时 | 实际帧率 |
| --- | --- | --- | --- |
| PC（CPU） | 320 | 60～150 ms | 6～12 FPS |
| 树莓派 4B | 320 | 200～500 ms | 2～5 FPS |
| 树莓派 4B | 640 | 800～2000 ms | &lt;1 FPS |
| 树莓派 Zero 2W | 320 | 1～2 s | 基本不可用 |

有主动散热的 4B 能稳定在上表下限；无散热跑 5 分钟就会因为降频掉到 2 倍耗时。

## 树莓派上跑 YOLO 的三条底线

| 要求 | 原因 |
| --- | --- |
| `imgsz=320` | 640 的推理量是 320 的 4 倍，树莓派扛不住 |
| 必须有散热 | ≥75 ℃ 触发降频，耗时翻倍且不可预测 |
| 不要每帧都检测 | 用"每 N 帧检测一次 + 中间沿用上次结果"降低负载，跟随类任务里这招很有效 |

第三条的具体做法（不在本例程里）：

```python
if frame_count % 3 == 0:
    detections, _ = detect_objects(model, image, CONFIDENCE)
    last_detections = detections
# 中间帧直接用 last_detections
```

## 预期效果与排查

画面左上角 `objects=N  time=XXX ms`，上方 `TEMP 62.3 C`；运行几分钟后温度上升、`time` 变大是正常的降频表现。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 启动卡 10 秒 | 首次推理预热 + 模型加载 | 正常，别放进循环 |
| `time` 从 300 涨到 900 | 温度降频 | 加散热，或降低检测频率 |
| 报 `YOLO_OFFLINE` 相关错误 | 模型路径不对，试图联网 | 检查 `common/` 或 `data/` 下 `yolo11n.pt` 是否存在 |
| 内存不足被杀 | 树莓派内存小 + 大输入 | `imgsz=320`，`data_queue_size=1` |
| 帧率只有 1 FPS | 还在用 640 | 改 `IMAGE_SIZE = 320` |
