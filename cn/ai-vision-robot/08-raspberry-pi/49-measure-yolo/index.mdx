## 前置条件

- 把 `camera.py`、`yolo_detection.py` 和本地模型 `data/yolo11n.pt` 复制到本页目录

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `load_yolo_resources()` | 只加载一次离线标签和模型 |
| `detect_objects(model, image, conf)` | 检测，返回字段和毫秒耗时 |
| 温度文件 | 启动时读一次，不在循环中重复读 |

## 完整示例

YOLO 是树莓派上最吃算力的一环，测出推理耗时和可达帧率。代码比较长，可以按住 Ctrl 滚动鼠标滚轮左右查看。

Esc to close", marked_image)\n\ndef main():\n    """读取一次处理器温度，打开相机运行本地YOLO性能观察。"""\n    try:\n        temperature = None                                  # 非树莓派没有温度文件时，画面显示None\n        temperature_file = Path("/sys/class/thermal/thermal_zone0/temp")\n        if temperature_file.exists():\n            temperature = int(temperature_file.read_text().strip()) / 1000  # 沿用45，系统温度除以1000换算为℃，启动时读取一次\n        with Camera() as camera:\n            run(camera, temperature)                        # 把本次温度值传给显示循环，不在循环中重复读取\n    except KeyboardInterrupt:\n        log_message("INFO", "yolo", "Ctrl+C 主动结束")\n    except (OSError, ValueError, cv2.error) as exc:\n        log_message("ERROR", "yolo", str(exc))\n    finally:\n        cv2.destroyAllWindows()\n\nif __name__ == "__main__":\n    main()'}

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `CONFIDENCE` | float | 0.25 | 检测置信度门槛 |
| `TEMP_WARN` | float | 75.0 ℃ | 过热提醒阈值 |
| `IMAGE_SIZE` | int | 320 | 输入尺寸，降尺寸换速度 |

> 本页是模块八收口，测出 YOLO 基线后按"降分辨率→缩 ROI→跳帧→换轻模型"逐项优化。
