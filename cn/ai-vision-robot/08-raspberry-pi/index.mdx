# 8 树莓派部署

## 模块目标

前面所有例程都在 PC 上跑，这个模块解决"上车"。树莓派和 PC 的差异不在代码，在**算力**和**环境**：依赖装不全、摄像头打不开、OpenCV 和 YOLO 慢到不能实时。所以顺序是：先体检环境 → 再跑最简单的循迹 → 然后驱动和相机一起验 → 最后用参数实测把性能压到能用。

## 例程顺序

| 例程 | 内容 | 关键点 |
| --- | --- | --- |
| 8.1 树莓派环境检查 | 系统、Python、依赖、相机、驱动逐项验证 | 先确认能 `import cv2` 和打开相机 |
| 8.2 树莓派跑循迹 | 最快能跑起来的完整动作 | 循迹不依赖视觉，先验证"能动" |
| 8.3 机器人与摄像头演示 | 控制器 + 摄像头同时工作 | 检查供电与带宽是否够 |
| 8.4 OpenCV 性能实测 | 测每帧耗时，找出瓶颈函数 | 分辨率与 ROI 是最大的两个杠杆 |
| 8.5 YOLO 性能实测 | 测推理耗时与可达到的帧率 | 降输入尺寸、跳帧检测、用轻量模型 |

## 优化顺序（别跳步）

> 先测再调，不要凭感觉改参数：**8.4 / 8.5 先把基线测出来**，然后按"降分辨率 → 缩 ROI → 跳帧 → 换轻模型"的顺序逐项试，每改一项重测一次。盲目调参只会让你不知道到底是哪一项起了作用。

## 前置

模块 8 之前的所有例程在 PC 上已经跑通。树莓派上的代码与 PC 完全一致，唯一常改的是分辨率和检测频率。
