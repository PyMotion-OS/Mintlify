## 前置条件

- 完成 [1.7 舵机移动](../../01-python-basics/07-servo-move/index)
- **车轮架空**（轮子离地，避免车跑出去）

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `robot.control()` | 电机动作前先拿控制权，退出时自动释放 |
| `robot.realtime.open(command_targets={"motor_speeds": (端口,)})` | 打开实时会话，声明本页要发哪几路命令 |
| `session.commands.motor_speeds.write({端口: 转速}, valid_for=1.0)` | 给**电机**写速度命令；`valid_for` 是命令的持续时间（有效时间），不能大于 2，给 1 就是持续转 1 秒，可以被后续命令更新 |
| `session.commands.motor_speeds.stop()` | 主动停机，不等命令到期 |
| `max()` | 返回两个数里较大的那个 |
| `min()` | 返回两个数里较小的那个 |

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `PORT_MOTOR` | int | 3 / 4 | 选择主动轮，3 接 M3 左轮、4 接 M4 右轮 |
| `RPM` | int | 本例 30 | 目标转速，正数正转、负数反转 |
| `MAX_RPM` | int | 60 | 允许的最高转速，超过被限幅 |
| `valid_for` | float | 1.0 / 2.0 | 命令存活秒数，到期设备端自动停机 |
| `command_targets` | dict | `{"motor_speeds": (端口,)}` | 声明本会话要发哪几路命令 |

> 本页 `valid_for` 到期 = **停机**。2.2 舵机的 `valid_for` 到期 = 角度保持——同一个参数，两种执行器语义不同。
