## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `reset_servos(robot)` | 本页定义：用普通位置命令让双舵机到达复位姿态（90°/90°），返回两个复位角度 |
| `robot.pwm_servos.move_to({端口: 角度, ...})` | 普通位置命令：发一次角度，让双舵机转到指定角度（1.7 学过） |
| `move_servos(commands, up_down_angle=90, left_right_angle=90)` | 本页定义：先限幅再发实时角度命令，返回实际发送的角度；省略参数时停在复位姿态 |
| `commands.pwm_position_servos.write({端口: 角度}, valid_for=0.3)` | 实时位置命令：走会话通道发角度，可带有效期 |
| 角度限幅（`if/elif`） | 上下 0～居中+15°、左右 0～180°，超范围夹到边界 |

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `PORT_UP_DOWN` | int | 4 | 上下舵机端口，限幅 0～居中+15° |
| `PORT_LEFT_RIGHT` | int | 5 | 左右舵机端口，可输入 0～180° |
| `UP_DOWN_HOME` / `LEFT_RIGHT_HOME` | int | 90 / 90 | 复位姿态：双 90° 约为居中，可按实际情况微调 |
| `valid_for` | float | 0.3 | 只约束命令本身，不约束角度——命令过期角度仍保持 |
| `move_servos` 两个默认参数 | int | 90 / 90 | 省略时停在复位姿态 |

> 本页是 1.7 的对照页：1.7 讲「怎么转到某个角度」，本页讲「实时命令与角度保持」——电机命令过期就停，舵机命令过期角度还在。

## 本页产出 · 舵机当前的方法和参数

- 普通位置命令：`robot.pwm_servos.move_to({端口: 角度})` —— 发一次转到位，适合复位
- 实时位置命令：`session.commands.pwm_position_servos.write({端口: 角度}, valid_for=0.3)` —— 会话内可反复发，命令过期角度仍保持
- 角度范围：上下 0～105°（90° 居中 +15°）、左右 0～180°，双 90° 为居中姿态，可按实际情况微调
