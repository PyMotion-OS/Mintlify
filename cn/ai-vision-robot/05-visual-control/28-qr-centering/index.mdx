## 本页目标

把二维码偏差变成**两个执行器**的动作：**横向交给双轮原地转**，**纵向交给 S4 俯仰**。这样云台不用左右摆（S5 保持居中），避免车轮和舵机抢着控制同一个方向。

同时引入防抖：不能一帧没识别到就判定"目标丢了"，要连续消失 0.5 秒才算。

## 前置条件

- 完成 5.2（舵机跟随）、4.3 或模块 3（循迹里的差速函数 `vw_to_rpm`）
- 同目录有 `camera.py`、`qr_observation.py`（5.3）、`servo_control.py`、`differential_drive.py`

## 动手步骤

**1. 在 `servo_control.py` 里补两个东西**

```python
CENTER_ERROR = 0.15      # 偏差进入中心 15% 就不再调整


def error_to_angle(error, angle, K):
    if error is None or abs(error) <= CENTER_ERROR:
        return angle
    return angle + error * K
```

**2. 新建 `28_qr_centering.py` 的核心部分**

```python
import time
import cv2
import pymotion as pm
from camera import Camera, log_message
from differential_drive import vw_to_rpm
from qr_observation import draw_qr_marks, find_qr
from servo_control import CENTER_ERROR, error_to_angle, move_servos, reset_servos

TARGET_TEXT = "GREETING"     # 只对准这个文字
LOST_SECONDS = 0.5           # 连续消失多久才认定丢失
W = 80                       # 横向转动强度，转不动就加大
SERVO_K = 5                  # 纵向每单位偏差调 5°
TRANSPORT = "wifi"
TIMEOUT = 15.0


def check_qr_state(qr_data, target_text, last_detected_time, lost_seconds):
    """三态判定：detected / missing / lost / waiting。"""
    if target_text is None:
        return "waiting", None

    current_time = time.monotonic()
    if qr_data is not None and qr_data["text"] == target_text:
        return "detected", current_time          # 本轮识别成功，刷新时刻

    if last_detected_time is None:
        return "waiting", None                   # 还没出现过，继续等

    missing_seconds = current_time - last_detected_time
    if missing_seconds < lost_seconds:
        return "missing", last_detected_time     # 短暂丢帧，不算丢

    return "lost", last_detected_time            # 超时才确认丢失


def run(camera, commands, up_down_angle, left_right_angle):
    last_detected_time = None
    last_state = None

    while True:
        image = camera.latest()
        qr_data = find_qr(image) if image is not None else None
        qr_state, last_detected_time = check_qr_state(
            qr_data, TARGET_TEXT, last_detected_time, LOST_SECONDS)

        if qr_state != "detected":
            left_rpm, right_rpm = 0, 0           # 未检测到：停车
        else:
            if abs(qr_data["error_x"]) <= CENTER_ERROR:
                left_rpm, right_rpm = 0, 0       # 横向已居中
            else:
                left_rpm, right_rpm = vw_to_rpm(0, -qr_data["error_x"] * W)  # 原地转

            # 纵向只动 S4，S5 保持 120° 居中
            up_down_angle = error_to_angle(qr_data["error_y"], up_down_angle, SERVO_K)
            up_down_angle, left_right_angle = move_servos(commands, up_down_angle, left_right_angle)

        if image is not None:
            cv2.imshow("QR centering - Esc to close", draw_qr_marks(image, qr_data))

        commands.motor_speeds.write({3: left_rpm, 4: right_rpm}, valid_for=0.3)   # M3 左轮 / M4 右轮

        if qr_state != last_state:
            log_message("INFO", "qr",
                        f"状态: {qr_state}  左轮: {left_rpm}  右轮: {right_rpm}")
            last_state = qr_state

        if cv2.waitKey(1) == 27:
            break
        time.sleep(0.1)


def main():
    try:
        with Camera() as camera:
            with pm.lite.connect(transport=TRANSPORT, timeout=TIMEOUT) as robot:
                with robot.control():
                    up_down_angle, left_right_angle = reset_servos(robot)
                    with robot.realtime.open(
                        command_targets={"motor_speeds": (3, 4), "pwm_position_servos": (4, 5)}
                    ) as session:
                        run(camera, session.commands, up_down_angle, left_right_angle)
    except (ValueError, pm.lite.LiteError) as exc:
        log_message("ERROR", "qr", f"{type(exc).__name__}: {exc}")
    except KeyboardInterrupt:
        log_message("INFO", "qr", "Ctrl+C主动结束")
    finally:
        cv2.destroyAllWindows()


if __name__ == "__main__":
    main()
```

**3. 运行，把二维码放到机器人侧前方**，看它先原地转、再抬头

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `TARGET_TEXT` | str | 卡片文字 | 只对准这个 ID，其它二维码一律无视 |
| `LOST_SECONDS` | float | 0.3～1.0 秒 | 太小会因单帧识别失败而抖停，太大会拖到真丢 |
| `W` | float | 60～120 | 横向转动强度，转不动就加，转过头就减 |
| `SERVO_K` | float | 3～8 | 纵向比例系数 |
| `CENTER_ERROR` | float | 0.15 | 偏差进入 15% 内视为已对准 |
| `-qr_data["error_x"]` | 符号 | **必须负号** | 目标在右（x 正）要右转，而 `vw_to_rpm` 的 W 正值是左转 |

## 数据结构

`check_qr_state()` 的四种返回：

| 状态 | 含义 | 车轮动作 |
| --- | --- | --- |
| `waiting` | 目标从未出现，或 `TARGET_TEXT` 为空 | 停 |
| `detected` | 本轮识别到指定 ID | 按偏差转向 |
| `missing` | 刚丢，但还在 `LOST_SECONDS` 容差内 | 停（防空转） |
| `lost` | 连续消失超过容差，确认丢失 | 停 |

## 预期效果与排查

二维码在画面左侧时机器人原地左转，进入中心带后停车；俯仰方向 S4 自动把二维码拉到画面竖向中部。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 越转越远 | 忘了 `-error_x` 负号 | 加负号，W 正值约定为左转 |
| 一直 `missing` 抖动 | `LOST_SECONDS` 太小 | 调到 0.5～0.8 |
| 车轮和云台打架 | S5 也在追横向 | 横向只给轮，S5 固定 120° |
| 只转不抬头 | `error_y` 一直是 0 | 检查二维码是否在画面竖向中心，`SERVO_K` 是否过大 |
