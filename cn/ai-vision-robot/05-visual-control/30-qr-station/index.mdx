## 前置条件

- Robot 通信正常（参考 [1.1 WIFI模式连接](../../01-python-basics/01-connect-wifi/index)，能打印出设备 ID）
- 把 `camera.py`、`qr_observation.py`、`differential_drive.py`、`line_control.py` 复制到本页目录
- 赛道上贴 STATION_A / STATION_B 二维码

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `check_qr_state(...)` | 5.3 产出，判断站台二维码是否连续消失 |
| `line_tracker_to_vw(...)` | 3.3 产出，五路循迹算 V/W |
| `vw_to_rpm(...)` | 2.4 产出，V/W 转双轮转速 |
| `run(camera, commands)` | 循环：循迹 → 遇站台减速 → 离站停机 → 恢复循迹 |

### 运行方式

```bash
python 30_qr_station.py
```

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `V` | int | 100 毫米/秒 | 默认循迹速度 |
| `SLOW_V` | int | 60 毫米/秒 | 站台任务减速速度 |
| `K` | int | 25 | 五路偏差增益 |
| `STATION_A/B` | str | — | 站台二维码文字 |

> 本页复用 2.4、3.3、5.3 的产出文件（差速、循迹、二维码观测）。
