## 本页目标

把循迹和视觉拼成一条**状态机**：正常循迹 → 看到站台二维码 → 减速 → 二维码离开 → 停机 8 秒（装卸货）→ 恢复循迹。这是模块 5 的收口，也是模块 7 综合项目的直接原型。

## 前置条件

- 完成 5.4（`check_qr_state`）、模块 3（循迹 `line_tracker_to_vw`）、模块 2（差速 `vw_to_rpm`）
- 场地贴好黑线，准备好 `STATION_A` / `STATION_B` 两张卡片

## 动手步骤

**1. 新建 `29_qr_station.py`**

**2. 写入核心代码**

```python
import time
import cv2
import pymotion as pm
from camera import Camera, log_message
from differential_drive import vw_to_rpm
from line_control import line_tracker_to_vw
from qr_observation import check_qr_state, draw_qr_marks, find_qr

V = 100          # 正常循迹速度 mm/s
SLOW_V = 60      # 站台区减速速度
K = 25           # 五路偏差每格对应的 W


def run(camera, data_queue, commands):
    state = "normal"          # normal / slow

    while True:
        # 第一步：取五路数据和最新图片
        sensor_data = data_queue.read(timeout=0.2)
        image = camera.latest()
        qr_data = None
        if image is not None:
            qr_data = find_qr(image)
            cv2.imshow("QR station - Esc to close", draw_qr_marks(image, qr_data))

        # 第二步：状态机
        if state == "normal" and qr_data is not None and qr_data["text"] in ("STATION_A", "STATION_B"):
            station_name = qr_data["text"]
            _, last_detected_time = check_qr_state(qr_data, station_name, None, 1)
            state = "slow"
            log_message("INFO", "station", f"站台: {station_name}  状态: slow")
        elif state == "slow":
            qr_state, last_detected_time = check_qr_state(
                qr_data, station_name, last_detected_time, 1)
            if qr_state == "lost":
                log_message("INFO", "station", f"站台: {station_name}  状态: stop")
                time.sleep(8)          # 停机作业；旧命令 0.35 秒后自动失效，车轮自然停
                state = "normal"
                log_message("INFO", "station", f"站台: {station_name}  状态: normal")
                continue

        # 第三步：按阶段选速度，算双轮转速
        speed = SLOW_V if state == "slow" else V
        if sensor_data is None:
            v, w, line_state = 0, 0, "waiting"      # 五路超时，不用上一轮数据
        else:
            v, w, line_state = line_tracker_to_vw(sensor_data.data.is_detected, speed, K)
        if image is None:
            v, w = 0, 0                              # 无图不动

        left_rpm, right_rpm = vw_to_rpm(v, w)
        commands.motor_speeds.write({3: left_rpm, 4: right_rpm}, valid_for=0.35)

        if line_state == "lost":
            log_message("INFO", "line", "路线断开，停止并结束运行")
            return                                   # 已发零速，安全退出
        if cv2.waitKey(1) == 27:
            return
```

**3. `main()` 里同时订阅五路数据和车轮命令**

```python
def main():
    try:
        with Camera() as camera:
            with pm.lite.connect(transport="wifi", timeout=15.0) as robot:
                with robot.control():
                    with robot.realtime.open(
                        data_sources=("line_tracker",),          # 只订阅五路，约 10 Hz
                        command_targets={"motor_speeds": (3, 4)},
                        frequency="medium",
                        data_queue_size=1,                        # 队列只留最新一条
                    ) as session:
                        run(camera, session.data, session.commands)
    except (ValueError, pm.lite.LiteError) as exc:
        log_message("ERROR", "station", f"{type(exc).__name__}: {exc}")
    except KeyboardInterrupt:
        log_message("INFO", "station", "Ctrl+C主动停机")
    finally:
        cv2.destroyAllWindows()
```

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `V` | int | 80～120 mm/s | 正常循迹速度 |
| `SLOW_V` | int | 40～70 mm/s | 站台区减速，给识别留时间 |
| `K` | float | 20～30 | 五路偏差到角速度的换算系数 |
| `data_queue_size` | int | **1** | 只保留最新帧，避免延迟累积到控制 |
| `frequency` | str | `"medium"` | 决定五路更新率，约 10 Hz |
| `valid_for` | float | 0.35 秒 | 命令有效期，超时自动失效等于急停 |
| 停机时长 | int | 8 秒 | 写死在 `time.sleep(8)`，装卸货作业时间 |

## 状态机

```
normal ──看到 STATION_A/B──▶ slow(减速循迹)
   ▲                              │
   │                       二维码连续消失 1 秒
   └──── sleep(8) 作业完成 ◀───── lost
```

关键点：**停机靠"不续发命令"实现**，而不是靠 `time.sleep` 期间保持零速下发。因为 `valid_for=0.35` 到期后旧命令自动失效，车轮自然停 —— 这是库层给的兜底安全设计。

## 预期效果与排查

小车沿黑线走，遇到 STATION_A 自动降到 60 mm/s，卡片离开视野 1 秒后整车停住，终端打印 `stop`，8 秒后自动继续循迹。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 看到站台不减速 | 卡片文字不是 `STATION_A/B` | 打印 `qr_data["text"]` 核对，或用 5.3 生成的卡片 |
| 减速后一直不停 | `check_qr_state` 里 `last_detected_time` 断了 | 确认 `station_name` 变量在 `slow` 分支里可访问 |
| 停车期间车轮仍转 | 有别的代码在续发命令 | 检查是否还有第二处 `motor_speeds.write` |
| 五路数据总超时 | `data_sources` 没写 `line_tracker` | 实时会话初始化参数必须声明 |
| 循迹抖动 | `data_queue_size` 太大 | 设为 1，只留最新帧 |
