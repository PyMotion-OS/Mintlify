# 5 视觉控制

## 模块目标

模块 4 只做了"看得见"，这个模块解决"看得见之后怎么动"。核心是三件事：**舵机云台**（两个自由度，上下 + 左右）、**偏差转角度**（像素误差 → 舵机增量）、**目标怎么选**（颜色最大块 / 二维码内容）。后面模块 6 的 YOLO 跟随是同一套控制逻辑换一个检测器。

## 例程顺序

| 例程 | 内容 | 关键点 |
| --- | --- | --- |
| 5.1 颜色舵机跟踪 | 颜色目标居中 | 死区 + 比例系数 K，偏差在死区内不动 |
| 5.2 二维码基础 | 识别并读出内容 | `pyzbar` 解码，卡片内容即站点编号 |
| 5.3 二维码居中 | 二维码移到画面中心 | 与 5.2 同一套偏差算法，只换目标源 |
| 5.4 二维码站点 | 识别站点 → 执行对应动作 | 内容到行为的映射表 |

## 共同套路

> 所有跟踪例程都是同一个三步循环：**取一帧 → 算目标偏差 → 按偏差调舵机**。差别只在"目标从哪来"。调参时先把死区调大让它稳住，再慢慢收小；`K` 太大会过冲来回摆。

## 前置

完成模块 4（尤其 4.6 颜色目标观测、4.7 实时颜色目标），能稳定拿到目标中心点坐标。
