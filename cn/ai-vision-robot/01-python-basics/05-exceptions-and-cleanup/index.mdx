## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `robot.status()` | 读一次状态包，里面 8 个字段 |
| `robot.close()` | 手动收尾，释放连接 |
| `try / except / finally` | 三种收尾：出错接住、最后一定执行 |
| `except KeyboardInterrupt` | Ctrl-C 也是一种异常，可以接住 |

这里故意不用 `with`（1.1 那种自动收尾写法），改成手动 `try/finally`——为了看见 `finally` 存在的理由：不管程序怎么结束（跑完、被打断、出错），`finally` 里的代码一定会执行。`with` 的机制 1.6 讲。

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `status.device_id` | str | 由设备决定 | 设备唯一编号 |
| `status.state` | str | `IDLE` / 其他 | 设备当前状态 |
| `status.lease_active` | bool | `True` / `False` | 是否持有控制权，1.6 会用到 |
| `status.estop_latched` | bool | `True` / `False` | 急停是否锁存，按下会一直锁着 |
| `status.estop_reason` | str | 空串 / 原因 | 急停原因，没触发是空字符串 |
| `status.fault_latched` | bool | `True` / `False` | 故障是否锁存 |
| `status.fault_reason` | str | 空串 / 原因 | 故障原因 |
| `status.age` | float | 秒 | 数据有多旧 |
