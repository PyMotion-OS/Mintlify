## 本页目标

先看一次五路循迹数据的完整结构，再用 `for` 循环采集 10 轮、把每轮有效数据存进列表，最后逐行打印。理解"持续采样"的写法——这是后续所有实时控制例程的骨架。

## 前置条件

- 完成例程 1.1、1.2
- 机器人放在赛道上或底面可控的桌面上（五路传感器需要能看到黑线/白底才有意义）

## 动手步骤

**1. 新建文件 `03_loops_and_lists.py`**

**2. 写入以下代码**

```python
import time
import pymotion as pm


def main():
    """连上后先看一次五路读数结构，再读 10 轮存进列表，最后逐轮打印。"""
    try:
        with pm.lite.connect(transport="wifi", timeout=15.0) as robot:
            tracker_line_data = robot.line_tracker(max_age=2.0)
            print(f"is_detected={tracker_line_data.is_detected} "
                  f"state={tracker_line_data.state} valid={tracker_line_data.valid} "
                  f"age={tracker_line_data.age}")

            rows = []                                   # 空列表，存每一轮五路数据
            for i in range(10):
                tracker_line_data = robot.line_tracker(max_age=2.0)
                if tracker_line_data.valid:             # 有效才存
                    rows.append(list(tracker_line_data.is_detected))
                time.sleep(0.3)                         # 读取间隔 0.3s

            for row in rows:
                print(row)

    except pm.lite.LiteError as exc:
        print(f"连接失败: {exc}")


if __name__ == "__main__":
    main()
```

**3. 运行**

```bash
python 03_loops_and_lists.py
```

## 参数说明

`robot.line_tracker(max_age=2.0)` 的完整返回结构：

```
{
  "is_detected": (False, True, True, False, False),   # 五路是否压到黑线，从左到右
  "state": "valid",                                    # 数据状态
  "valid": true,                                       # 能不能用
  "age": 0.05                                          # 数据有多旧，单位秒
}
```

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `max_age` | float | 秒，本例 2.0 | 超过则抛错，避免拿到过期数据 |
| `is_detected` | tuple[bool] × 5 | `True` = 压到黑线 | 顺序从左到右，循迹算法的基础 |
| `state` | str | `valid` / 其他 | 无效时说明原因 |
| `valid` | bool | `True` / `False` | 先判它再使用数据 |
| `age` | float | 秒 | 数据新鲜度 |
| `range(10)` | int | 本例 10 轮 | 采样轮数，配合 `sleep(0.3)` 约 3 秒 |
| `time.sleep(0.3)` | float | 秒 | 采样间隔，太小会读到重复值 |

## 预期效果与排查

```
is_detected=(False, True, True, False, False) state=valid valid=True age=0.05
[False, True, True, False, False]
[False, True, True, False, False]
[True, True, False, False, False]
...
```

把车在线上左右移动，列表里的 `True` 位置应跟着移动。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 打印的列表条数少于 10 | 部分轮次 `valid` 为假被跳过 | 正常，说明过滤生效；需要固定条数就改存 `None` |
| 每行完全一样 | `sleep` 太短，读到同一帧缓存 | 加长间隔或降低采样频率 |
| `is_detected` 全是 `False` | 传感器离地太高或底面无对比 | 调整高度到 5～10 mm，用黑白两色底测试 |
