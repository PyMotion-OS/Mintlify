## 前置条件

- Robot 通信正常（参考 [1.1 WIFI模式连接](../01-connect-wifi/index)，能打印出设备 ID）

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `robot.line_tracker()` | 读五路循迹；车底并排 5 个红外探头看地上黑线 |
| `for i in range(10)` | 计数循环，重复 10 轮 |
| `for row in rows` | 遍历列表，逐个取出每轮记录 |
| `rows.append(...)` | 把每轮结果存进列表，攒起来最后一起看 |
| `time.sleep(0.3)` | 让程序在这个位置等 0.3 秒，本程序就是每隔 0.3 读一次 |

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `tracker_line_data.is_detected` | 元组 | 5 个 `True` / `False` | 五路探头是否压到黑线，依次对应车底从左到右 5 个探头 |
| `tracker_line_data.state` | str | `valid` / 其他 | 数据状态 |
| `tracker_line_data.valid` | bool | `True` / `False` | 有效才存进列表 |
| `tracker_line_data.age` | float | 秒 | 数据有多旧 |
