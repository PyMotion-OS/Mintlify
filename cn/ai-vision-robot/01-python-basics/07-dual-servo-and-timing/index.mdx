## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `robot.pwm_servos.move_to({端口: 角度, ...})` | 批量发角度，PWM 舵机按角度定位 |
| `robot.pwm_servos.stop()` | 关 PWM 输出，放 `finally` |
| `time.monotonic()` | 只增不减的时钟，适合算耗时 |

PWM 舵机像机械臂的关节：你给它目标角度，它自己转过去。它不会汇报「到了」，所以要 `sleep` 等一会儿——这是舵机的标准写法。

      code={'import time\n\nimport pymotion as pm\n\nPORT_UP_DOWN = 4                           # 上下舵机接 PWM 端口 4\nPORT_LEFT_RIGHT = 5                        # 左右舵机接 PWM 端口 5\n\n\ndef main():\n    """复位 → 移动 → 复位三次动作，间隔 0.2s / 0.5s，最后打印总耗时。"""\n    try:\n        with pm.lite.connect(transport="wifi", timeout=15.0) as robot:\n            with robot.control():                 # 舵机也是执行器，先拿控制权（1.6）\n                start = time.monotonic()          # 开始前记时间：只增不减，适合算耗时\n\n                try:\n                    # 第一次：复位姿态\n                    robot.pwm_servos.move_to({PORT_UP_DOWN: 75, PORT_LEFT_RIGHT: 120})\n                    print("复位: 上下 75°，左右 120°")\n                    time.sleep(0.2)               # 两次动作之间停 0.2 秒\n\n                    # 第二次：转到水平位\n                    robot.pwm_servos.move_to({PORT_UP_DOWN: 70, PORT_LEFT_RIGHT: 120})\n                    print("移动: 上下 70°，左右 120°")\n                    time.sleep(0.5)               # 停 0.5 秒\n\n                    # 第三次：回到复位姿态\n                    robot.pwm_servos.move_to({PORT_UP_DOWN: 75, PORT_LEFT_RIGHT: 120})\n                    print("复位: 上下 75°，左右 120°")\n                finally:\n                    robot.pwm_servos.stop()       # 不管动作怎么中断，都关掉 PWM 输出\n\n                print(f"执行时间: {time.monotonic() - start:.2f} 秒")\n\n    except pm.lite.LiteError as exc:\n        print(f"连接失败（{exc}）")\n\n\nif __name__ == "__main__":\n    main()'}

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `PORT_UP_DOWN` | int | 本例 4 | 上下舵机端口，角度范围 0～85°，70° 是水平 |
| `PORT_LEFT_RIGHT` | int | 本例 5 | 左右舵机端口，角度范围 60～180°，120° 是居中 |
| `time.monotonic()` | float | 秒 | 只增不减的时钟，两次相减得到耗时 |

## sleep 的边界

一次性动作 `sleep` 等一等是对的：舵机转到位就完事，没有别的事要做。但如果动作要连续调整——比如跟着目标转头——`sleep` 会把程序卡成一格一格的。模块二第一课就会遇到这个问题，解决办法叫实时命令（realtime）。
