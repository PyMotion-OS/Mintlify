## 本页目标

把"电压分三档"的判断逻辑抽成一个函数 `check_V(V, low, full)`，主程序只负责读数据和调用函数。学会把阈值做成参数，而不是写死在判断里——后面调整行为时不用改逻辑。

## 前置条件

- 完成例程 1.1
- 机器人已装电池并上电（读得到真实电压）

## 动手步骤

**1. 新建文件 `04_functions_and_parameters.py`**

**2. 写入以下代码**

```python
import time
import pymotion as pm

LOW = 10.5                                 # 告警电压，伏特
FULL = 12.5                                # 标称电压，伏特


def check_V(V, low, full):
    """电压分三档：偏低 / 一般 / 充足；读不到单独说。"""
    if V is None:                          # 读不到电压时给的是 None
        print("电压: 读不到（None）")
    elif V < low:
        print(f"电压: {V:.2f} V，偏低")
    elif V < full:
        print(f"电压: {V:.2f} V，一般")
    else:
        print(f"电压: {V:.2f} V，充足")


def main():
    """连上后读三次电压，每读一次立刻判一次。"""
    try:
        with pm.lite.connect(transport="wifi", timeout=15.0) as robot:
            for i in range(3):
                power_data = robot.power()
                check_V(power_data.voltage, LOW, FULL)
                time.sleep(0.5)
    except pm.lite.LiteError as exc:
        print(f"连接失败: {exc}")


if __name__ == "__main__":
    main()
```

**3. 运行**

```bash
python 04_functions_and_parameters.py
```

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `LOW` | float | 本例 10.5 | 低于此值判"偏低"，按电池化学体系调整 |
| `FULL` | float | 本例 12.5 | 达到此值判"充足" |
| `V` | float / None | 伏特 | `robot.power().voltage` 的取值，可能为 `None` |
| `low` / `full` | float | 由调用方传入 | 做成参数，换电池组只改常量 |
| `check_V` 返回值 | None | — | 只打印，不返回，便于对照 |

## 预期效果与排查

满电时输出类似：

```
电压: 12.31 V，一般
电压: 12.31 V，一般
电压: 12.31 V，一般
```

拔掉电池供电改 USB 供电时，可能变成 `读不到（None）`。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 一直是 `None` | 设备不支持或未上电检测 | 确认电池已接，`robot.power()` 需设备供电正常 |
| 三次数值完全相同 | `sleep` 太短，电压变化本就缓慢 | 属正常，改 30 秒一次观察放电曲线 |
| 报 `AttributeError: voltage` | 用了别的对象名 | `power()` 返回对象的字段就是 `voltage` |
