## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `robot.power()` | 读一次电源数据 |
| `def check_V(V)` | 自定义函数：把判断逻辑装进函数反复用，主流程只剩「读数 + 调用」 |

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `power_data.voltage` | float / None | 伏特 | 电池电压，读不到时为 `None` |
| `LOW` | float | 本例 10.5 | 低于它判「偏低」；改大更早告警 |
| `FULL` | float | 本例 12.5 | 达到它判「充足」；改小更容易判「充足」 |
