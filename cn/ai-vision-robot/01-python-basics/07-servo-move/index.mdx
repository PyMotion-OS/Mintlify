## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `robot.pwm_servos.move_to({端口: 角度, ...})` | 批量发角度，PWM 舵机按角度定位 |
| `time.monotonic()` | 只增不减的时钟，适合算耗时 |

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `PORT_UP_DOWN` | int | 本例 4 | 上下舵机端口，可输入 0～180°，90° 约为居中 |
| `PORT_LEFT_RIGHT` | int | 本例 5 | 左右舵机端口，可输入 0～180°，90° 约为居中 |
| `time.monotonic()` | float | 秒 | 只增不减的时钟，两次相减得到耗时 |
