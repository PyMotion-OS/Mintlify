## 模块目标

这是整本手册的第一站，用来完成两件事：**认识这台 Robot，并学会控制它所需的 Python 基础**。完成本模块后，你可以做到——

- 连接 Robot，读取它的设备信息
- 认识 Robot 的硬件模块：超声波、循迹、电池、电机、舵机
- 读取传感器数据（超声波、循迹、电池电压）
- 控制电机前进、后退，控制舵机转到指定角度
- 用循环持续采样、用函数封装判断逻辑、用 `with` 保证异常时设备被正确释放

这些是后续运动、循迹、视觉例程的共同基础。

## 学习建议

1. 每个例程先跑通再改参数，改完再运行一次，观察输出变化
2. 建议按顺序完成，不要跳过——1.3 的列表、1.4 的函数、1.6 的控制权会在后续模块大量复用
