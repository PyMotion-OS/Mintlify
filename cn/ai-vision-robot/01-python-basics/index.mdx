## 模块目标

这个模块不碰电机，只解决一件事：**让代码能可靠地和机器人对话**。学完你应该能做到——连上设备、读出传感器数据、用循环持续采样、用函数封装判断逻辑、用 `with` 保证异常时设备一定被正确释放。

后面所有运动、循迹、视觉例程都建立在这几个动作上，所以这里慢一点值得。

## 例程顺序

| 例程 | 内容 | 学完能做什么 |
| --- | --- | --- |
| 1.1 WIFI模式连接 | `connect()`、设备信息 | 确认环境和设备都正常 |
| 1.2 超声波测距 | 读超声波 + `if` 判断 | 把读数分成"过近/正常/未知" |
| 1.3 循迹与循环 | `for` 循环持续采样 | 攒一段数据看趋势 |
| 1.4 电压与函数 | 把判断封装成函数 | 同一逻辑多处复用 |
| 1.5 状态与异常清理 | `try/except/finally` | 断网、Ctrl-C 都不留残局 |
| 1.6 电机与类 | 自定义上下文管理器 | 进出自动停机的电机组 |
| 1.7 双舵机与计时 | PWM 舵机 + `time.monotonic()` | 动作与耗时测量，模块收尾 |

## 学习建议

1. 每个例程都**先跑通再改参数**，改完再跑一次，观察输出变化
2. 例程之间是递进的，不要跳着做——1.3 的列表、1.4 的函数、1.6 的控制权在后续模块会大量复用
