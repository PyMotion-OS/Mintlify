## 前置条件

- Robot 通信正常（参考 [1.1 WIFI模式连接](../01-connect-wifi/index)，能打印出设备 ID）
- 机器人架空（轮子离地）或前方留出至少 1 米空地

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `with robot.control()` | 先拿控制权再动作，防止两个程序同时指挥 |
| `robot.motors.set_speeds({端口: 转速}, duration)` | 给电机发转速，`duration` 秒后自动停 |
| `robot.motors.stop()` | 立即停止所有电机 |
| `class / __init__ / __enter__ / __exit__` | 自定义类，实现 1.1 同款 `with` 协议 |

这里回答「为什么要写类」：1.1 的 `with` 不是魔法，它是一种约定——进的时候做什么、出的时候做什么。`SafeMotors` 把同样的约定套在电机上，进出自动停，忘不了。

### 运行方式

```bash
python safe_motors.py
```

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `PORT_LEFT` / `PORT_RIGHT` | int | 本例 3 / 4 | 左轮 M3、右轮 M4，接线改了这里也要改 |
| `RPM` | int | 本例 30 | 转速，转/分钟；正数前进，负数后退 |
| `duration` | float | 秒，本例 2 | 命令有效期，到期自动停 |
