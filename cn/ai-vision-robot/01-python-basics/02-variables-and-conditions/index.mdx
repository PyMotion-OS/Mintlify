## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `robot.ultrasonic()` | 读一次超声波距离；超声波像蝙蝠发声音听回声，算出前方障碍物有多远 |
| `if / elif / else` | 按条件分成三档，依次判断，命中一个就停 |

## 完整示例

代码比较长，可以按住 Ctrl 滚动鼠标滚轮左右查看。

      code={'import pymotion as pm\n\nSTOP = 200                                 # 判断阈值：200 毫米以内算"过近"\n\n\ndef main():\n    """连接后读一次距离，判断这次读数属于哪一档。"""\n    try:\n        with pm.lite.connect(transport="wifi", timeout=15.0) as robot:\n            ultrasonic_data = robot.ultrasonic()            # 读一次超声波数据\n\n            print("超声波传感器的数据结构：")                            # 完整字段，一个不省\n            print("{")\n            print(f\'  "distance": {ultrasonic_data.distance},\')        # 距离，毫米\n            print(f\'  "state": "{ultrasonic_data.state}",\')            # 状态文字\n            print(f\'  "valid": {ultrasonic_data.valid},\')              # 这条数据能不能用\n            print(f\'  "age": {ultrasonic_data.age}\')                   # 数据有多旧，单位秒\n            print("}")\n\n            # valid=False 时没有 distance 可用，必须先查它再做判断\n            if not ultrasonic_data.valid:\n                print(f"未知: None（{ultrasonic_data.state}）")\n            elif ultrasonic_data.distance < STOP:                      # 比阈值小就是过近\n                print(f"过近: {ultrasonic_data.distance:.0f} mm")\n            else:                                                      # 其余都算正常\n                print(f"正常: {ultrasonic_data.distance:.0f} mm")\n\n    except pm.lite.LiteError as exc:\n        print(f"连接失败（{exc}）")\n\n\nif __name__ == "__main__":\n    main()'}

## 参数说明

<ParamField path="ultrasonic_data" type="object">
  一次超声波读数的完整返回，下面的 `distance` / `state` / `valid` / `age` 都是它的字段。
</ParamField>

<ParamField path="ultrasonic_data.distance" type="float">
  前方障碍物距离，单位毫米；无效读数时为 `None`。
</ParamField>

<ParamField path="ultrasonic_data.state" type="string">
  数据状态文字，`valid` 表示可用，其他值说明无效原因。
</ParamField>

<ParamField path="ultrasonic_data.valid" type="boolean">
  这条数据能不能用；先判它、再判 `distance`。
</ParamField>

<ParamField path="ultrasonic_data.age" type="float">
  数据有多旧，单位秒。
</ParamField>

<ParamField path="STOP" type="int">
  判断阈值（毫米），本例用 200；改小更灵敏，改大更迟钝。
</ParamField>
