## 前置条件

- Robot 通信正常（参考 [1.1 WIFI模式连接](../01-connect-wifi/index)，能打印出设备 ID）

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `robot.ultrasonic()` | 读一次超声波距离；超声波像蝙蝠发声音听回声，算出前方障碍物有多远 |
| `if / elif / else` | 按条件分成三档，依次判断，命中一个就停 |

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `ultrasonic_data.distance` | float | 毫米 | 前方障碍物距离，无效读数时为 `None` |
| `ultrasonic_data.state` | str | `valid` / 其他 | 数据状态，无效时用它说明原因 |
| `ultrasonic_data.valid` | bool | `True` / `False` | 先判它再判 `distance` |
| `ultrasonic_data.age` | float | 秒 | 数据有多旧 |
| `STOP` | int | 本例 200 | 判断阈值，毫米；改小更灵敏，改大更迟钝 |
