## 本页目标

写两个纯计算函数：`classify_pattern()` 判断五路图案属于哪一类并算出偏差，`line_tracker_to_vw()` 把偏差乘增益变成 W。本页**只打印结果、不发电机指令**，先把算法看明白。

## 前置条件

- 完成模块 2
- 车放在黑线赛道上（或黑白卡纸），五路传感器高度 5～10 mm

## 动手步骤

**1. 新建 `13_line_classification_and_motion.py`（内容见下）**

**2. 手动左右移动车，观察打印的分类与 W 变化**

```python
import time
import pymotion as pm

V = 80                     # 基础前进速度 mm/s
K = 25                     # 转弯增益，每格偏差 25 °/s
MAX_LINE_SENSORS = 3       # 正常线最多连续触发 3 个探头
SENSOR_POSITIONS = (-2, -1, 0, 1, 2)

PATTERN_NAMES = {"line": "单段连续线", "lost": "没有探测到线",
                 "wide": "连续图案过宽", "multiple": "探测到多段图案",
                 "invalid": "数据无效"}


def classify_pattern(sensor_states):
    """五路状态 → (图案分类, 偏差)"""
    if sensor_states is None or len(sensor_states) != 5:
        return "invalid", None
    detected = [SENSOR_POSITIONS[i] for i in range(5) if sensor_states[i]]
    if not detected:
        return "lost", None
    if detected[-1] - detected[0] + 1 != len(detected):
        return "multiple", None            # 中间有断档
    if len(detected) > MAX_LINE_SENSORS:
        return "wide", None
    return "line", sum(detected) / len(detected)   # 质心即偏差


def line_tracker_to_vw(sensor_states, v, k):
    """五路状态 → (V, W, 分类)"""
    pattern_type, line_offset = classify_pattern(sensor_states)
    if pattern_type != "line":
        return 0, 0, pattern_type          # 不是正常线就不动
    w = k * (0 - line_offset)              # 线偏左(负) → W 为正 → 左转
    return v, w, pattern_type


def main():
    last = None
    try:
        with pm.lite.connect(transport="wifi", timeout=15.0) as robot:
            while True:
                data = robot.line_tracker(max_age=1.0)
                v, w, pattern_type = line_tracker_to_vw(data.is_detected, V, K)
                now = (data.is_detected, pattern_type, v, w)
                if now != last:
                    print(f"五路: {data.is_detected}\n分类: {PATTERN_NAMES[pattern_type]}  "
                          f"V: {v:>2} mm/s  W: {w:>5} °/s")
                    last = now
                time.sleep(0.35)
    except KeyboardInterrupt:
        print("Ctrl+C 结束观察")


if __name__ == "__main__":
    main()
```

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `V` | int | 本例 80 mm/s | 基础前进速度，分类正常时才用 |
| `K` | float | 本例 25 | 增益，偏一格加 25 °/s；越大越灵敏越易摆 |
| `MAX_LINE_SENSORS` | int | 3 | 超过视为宽线（十字路口会触发） |
| `SENSOR_POSITIONS` | tuple | (-2,-1,0,1,2) | 五路探头位置，决定偏差刻度 |
| `line_offset` | float | -2～2 | 负=线偏左，0=居中，正=偏右 |

## 预期效果与排查

线在正中时打印 `分类: 单段连续线 V: 80 W: 0`；把车向左推，`is_detected` 左侧变 True，W 变正（左转修正）。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 一直 `没有探测到线` | 高度不对或线太细 | 降低安装高度，用 20 mm 宽黑胶带 |
| 十字路口被判 `wide` | 连续触发超过 3 个 | 属正常设计，可提高 `MAX_LINE_SENSORS` |
| W 剧烈跳动 | `K` 太大或 `sleep` 太短 | 降 `K`、加大采样间隔 |
