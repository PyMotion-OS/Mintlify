# 3 循迹

## 模块目标

把五路循迹的 `True/False` 变成机器人的运动。三步走：**分类图案**（是不是一条正常线）→ **算偏差**（线在心左边还是右边）→ **比例控制**（偏得越多转得越急）。第三页再把避障叠加上去，做成"安全循迹"。

## 例程顺序

| 例程 | 内容 | 关键点 |
| --- | --- | --- |
| 3.1 循迹分类与运动计算 | 五路 → 图案分类 + V/W | 质心法算偏差、比例控制 |
| 3.2 循迹控制 | 接上实时数据真正跑起来 | `medium` 频率 + 0.35 秒有效期 |
| 3.3 安全循迹 | 循迹 + 避障叠加 | 两个策略函数串起来，丢线即停 |

## 关键概念

| 概念 | 含义 |
| --- | --- |
| 图案分类 | `line` 正常单段线、`lost` 丢线、`wide` 线太宽、`multiple` 多段 |
| 偏差 `line_offset` | 触发探头的平均位置，负=线偏左，正=线偏右 |
| 增益 `K` | 每单位偏差增加多少 °/s 的 W，太大画龙、太小拐不过弯 |

> 地面光线、轮胎打滑都会影响效果。先在直线上把 `K` 调到不抖，再上弯道。
