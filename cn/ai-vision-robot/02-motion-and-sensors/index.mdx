# 2 运动与传感器

## 模块目标

模块 1 解决了"能对话"，这个模块解决"能动、能感知、能停"。核心是三件事：**实时会话**（`realtime.open()`）、**数据队列**（`session.data`）、**带有效期的指令**（`valid_for`）。后面的循迹与视觉控制都是它们的组合。

## 例程顺序

| 例程 | 内容 | 关键点 |
| --- | --- | --- |
| 2.1 单轮电机控制 | 单轮正反转 | `valid_for` 到期自动停机 |
| 2.2 实时数据队列 | 同时收超声波 + 五路循迹 | `read()` 的完整返回结构 |
| 2.3 差速驱动 | V/W → 左右轮 RPM | 两轮差速运动学 |
| 2.4 键盘遥控 | 方向键控制 | 多键组合 + 失焦停机 |
| 2.5 避障停车 | 按距离分档减速/停机 | 状态机式判断 |
| 2.6 安全停车 | 输入 stop / 超时 / 断网都能停 | 多线程 + 指令有效期 |

## 安全提醒

> 前三个例程务必**把车架空**。所有电机指令都带 `valid_for`——断网或程序崩溃时车会自己停，但不要依赖它，手要随时能断电。
