## 本页目标

用 tkinter 窗口抓方向键，把按键合成 V/W，每 100 ms 发一次双轮速度。重点看**安全设计**：失焦清键、关窗停机、指令有效期 0.35 秒。

## 前置条件

- 完成例程 2.3（复用它的 `vw_to_rpm`，需同目录放 `differential_drive.py`）
- 车轮架空或留 2 米空地
- 电脑需有图形界面（Windows/macOS 直接跑）

## 动手步骤

**1. 新建 `10_keyboard_control.py`，并把 2.3 的 `differential_drive.py` 复制到同目录**

**2. 写入代码**

```python
import tkinter as tk
import pymotion as pm
from differential_drive import vw_to_rpm

V = 106                    # 前后速度 mm/s
W = 40                     # 左右角速度 度/s
PORT_LEFT, PORT_RIGHT = 3, 4


def drive(commands, v, w):
    left, right = vw_to_rpm(v, w)
    commands.motor_speeds.write(
        {PORT_LEFT: left, PORT_RIGHT: right}, valid_for=0.35)


def run_window(commands):
    window = tk.Tk()
    window.title("键盘遥控")
    window.keys = set()
    tk.Label(window, text="点击窗口后按方向键；上下前后，左右转向，可组合",
             padx=24, pady=24).pack()

    def tick():
        v = w = 0
        if "Up" in window.keys: v += V
        if "Down" in window.keys: v -= V
        if "Left" in window.keys: w += W
        if "Right" in window.keys: w -= W
        drive(commands, v, w)          # 没按键也持续发 0 RPM
        window.after(100, tick)

    def on_press(event):
        if event.keysym in ("space", "Escape"):
            window.keys.clear()
            drive(commands, 0, 0)
        elif event.keysym in ("Up", "Down", "Left", "Right"):
            window.keys.add(event.keysym)

    def on_release(event):
        window.keys.discard(event.keysym)

    def on_focus_out(_event):
        window.keys.clear()
        drive(commands, 0, 0)

    window.bind("<KeyPress>", on_press)
    window.bind("<KeyRelease>", on_release)
    window.bind("<FocusOut>", on_focus_out)
    window.after(100, tick)
    try:
        window.mainloop()
    finally:
        commands.motor_speeds.stop()


def main():
    try:
        with pm.lite.connect(transport="wifi", timeout=15.0) as robot:
            with robot.control():
                with robot.realtime.open(command_targets={"motor_speeds": (PORT_LEFT, PORT_RIGHT)}) as session:
                    run_window(session.commands)
    except Exception as exc:
        print(f"出错: {type(exc).__name__}: {exc}")


if __name__ == "__main__":
    main()
```

**3. 运行后点一下窗口再按键**

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `V` | int | 本例 106 | 前后速度，越大越快 |
| `W` | int | 本例 40 | 转向角速度 |
| `valid_for` | float | 0.35 秒 | 略大于 100 ms 发送周期，断发即停 |
| `window.after(100, tick)` | int | 毫秒 | 刷新周期，别低于 50 ms |
| `space` / `Escape` | 键 | — | 清空按键并立即发 0 RPM |

## 预期效果与排查

按上键前进，上下+左右可斜走；松键后 0.35 秒内停下；切到别的窗口车立即停。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 按键没反应 | 窗口没获得焦点 | 先鼠标点一下窗口 |
| 松键后还冲一下 | 指令有效期 0.35 秒 | 正常，需更灵敏就把 tick 与 `valid_for` 一起调小 |
| 报 `ModuleNotFoundError: differential_drive` | 没复制 2.3 的函数文件 | 把 `differential_drive.py` 放到同目录 |
