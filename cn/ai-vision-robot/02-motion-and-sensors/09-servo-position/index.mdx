## 前置条件

- 完成 [1.7 双舵机与计时](../../01-python-basics/07-dual-servo-and-timing/index)（1.7 用 `move_to` 做过动作，本页换成实时命令）

## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `robot.pwm_servos.move_to({端口: 角度, ...})` | 普通位置命令：发一次角度，舵机自己转过去（1.7 学过，本页只做复位） |
| `commands.pwm_position_servos.write({端口: 角度}, valid_for=0.3)` | 实时位置命令：走会话通道发角度，可带有效期 |
| 角度限幅（`if/elif`） | 上下 0～85°、左右 60～180°，超范围夹到边界 |
| `def move_servos(commands, up_down_angle=70, left_right_angle=120)` | 带默认参数的函数，省略时停在复位姿态 |

等待双舵机到达复位姿态\n    return UP_DOWN_HOME, LEFT_RIGHT_HOME                    # 后续角度从复位姿态开始计算\n\n\ndef move_servos(commands, up_down_angle=70, left_right_angle=120):\n    """限制双舵机角度并发送实时命令，返回实际发送的两个角度。"""\n    # S4 最多抬到 85°\n\n    if left_right_angle < 60:\n        left_right_angle = 60                               # S5 转不到 60° 以下\n    elif left_right_angle > 180:\n        left_right_angle = 180                              # S5 最多转到 180°\n\n    # 0.3 秒只约束命令本身：过期后不再重发，舵机仍停在最后的角度\n    commands.pwm_position_servos.write(\n        {PORT_UP_DOWN: up_down_angle, PORT_LEFT_RIGHT: left_right_angle}, valid_for=0.3\n    )\n    return up_down_angle, left_right_angle                  # 主程序继续使用限制后的安全角度\n\n\ndef main():\n    """先复位到 70°/120°，再用实时命令各偏 10°，观察"命令到期但角度仍保持"。"""\n    try:\n        with pm.lite.connect(transport="wifi", timeout=15.0) as robot:\n            with robot.control():                           # 舵机也是执行器，先拿控制权\n\n                # 第一步：move_to 复位。普通位置命令，不需要实时会话（1.7 学过）\n                up_down_angle, left_right_angle = reset_servos(robot)\n                print(f"复位: 上下 {up_down_angle}°，左右 {left_right_angle}°")\n\n                # ## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `PORT_UP_DOWN` | int | 4 | 上下舵机端口，角度范围 0～85° |
| `PORT_LEFT_RIGHT` | int | 5 | 左右舵机端口，角度范围 60～180° |
| `UP_DOWN_HOME` / `LEFT_RIGHT_HOME` | int | 70 / 120 | 复位姿态：上下 70°、左右居中 120° |
| `valid_for` | float | 0.3 | 只约束命令本身，不约束角度——命令过期角度仍保持 |
| `move_servos` 两个默认参数 | int | 70 / 120 | 省略时停在复位姿态 |

> 本页是 1.7 的对照页：1.7 讲「怎么转到某个角度」，本页讲「实时命令与角度保持」——电机命令过期就停，舵机命令过期角度还在。
