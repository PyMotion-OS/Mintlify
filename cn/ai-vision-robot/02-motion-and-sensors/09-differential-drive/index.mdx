## 本页目标

写两个函数：`vw_to_rpm(v, w)` 把"前进速度 + 转弯快慢"换成左右轮 RPM，`limit_rpm()` 做同比例限幅。这样你以后只需想"往哪走、走多快"，不用再想"左右轮各多少转"。

## 前置条件

- 完成例程 2.1
- 车轮架空，或前方留 1.5 米空地
- 已知轮子半径和轮距（本例 R=33.75 mm、D=160 mm）

## 动手步骤

**1. 新建 `09_differential_drive.py`**

**2. 写入代码**

```python
import math
import time
import pymotion as pm

ACTION = "spin_left"        # 动作名，见 ACTIONS
V = 175                     # 前进速度 mm/s
W = 60                      # 角速度 度/s
R = 33.75                   # 轮子半径 mm
D = 160.0                   # 左右轮间距 mm
PORT_LEFT, PORT_RIGHT = 3, 4
MAX_RPM = 60

ACTIONS = {
    "forward": (V, 0), "backward": (-V, 0),
    "forward_left": (V, W), "forward_right": (V, -W),
    "spin_left": (0, W), "spin_right": (0, -W),
}


def limit_rpm(left, right):
    """同尺度限幅：超上限就两边一起缩，弯道形状不变"""
    fast = max(abs(left), abs(right))
    if fast > MAX_RPM:
        scale = MAX_RPM / fast
        left, right = left * scale, right * scale
    return round(left), round(right)


def vw_to_rpm(v, w):
    """V/W → 左右轮 RPM"""
    w = math.radians(w)                 # 度/秒 → 弧度/秒
    c = 2 * math.pi * R                 # 轮子一圈走多远
    left_v = v - w * D / 2
    right_v = v + w * D / 2
    return limit_rpm(left_v * 60 / c, right_v * 60 / c)


def main():
    v, w = ACTIONS[ACTION]
    left, right = vw_to_rpm(v, w)
    print(f"动作: {ACTION}  左轮: {left} RPM  右轮: {right} RPM")
    with pm.lite.connect(transport="wifi", timeout=15.0) as robot:
        with robot.control():
            with robot.realtime.open(command_targets={"motor_speeds": (PORT_LEFT, PORT_RIGHT)}) as session:
                session.commands.motor_speeds.write(
                    {PORT_LEFT: left, PORT_RIGHT: right}, valid_for=1.7)
                time.sleep(1.5)
                session.commands.motor_speeds.stop()


if __name__ == "__main__":
    main()
```

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `V` | float | mm/s | 前进速度，负值后退 |
| `W` | float | 度/s | 正为左转、负为右转 |
| `R` | float | 本例 33.75 | 轮子半径，换轮子必须改 |
| `D` | float | 本例 160.0 | 轮距，影响转弯半径 |
| `MAX_RPM` | float | 60 | 单轮上限，超出按比例缩，保持弯道比例 |
| `ACTION` | str | `forward`～`spin_right` | 从 `ACTIONS` 表选动作 |

## 预期效果与排查

选 `spin_left` 时打印 `左轮: -5 RPM 右轮: 5 RPM`（原地左转）——左轮反转、右轮正转。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 车往反方向转 | W 符号理解反了 | 左转用正 W；左右轮接反也会这样 |
| 走直线跑偏 | `D`、`R` 与实际不符 | 用尺子量轮距与轮径后改常量 |
| 转弯很慢 | 两轮同时被限幅 | 提高 `MAX_RPM` 或减小 `V` |
