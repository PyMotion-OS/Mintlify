## 关键函数

| 函数 / 语法 | 说明 |
| --- | --- |
| `robot.realtime.open(data_sources=("ultrasonic", "line_tracker"))` | 声明本会话要收哪几种数据（与 `command_targets` 是同一次 `open()` 的两个方向） |
| `session.data.read(timeout=0.5)` | 从队列取一条；队列空时最多等 0.5 秒，超时返回 `None` |
| `sensor_data.source` | 这条数据来自哪个传感器，用它分派 |
| `pprint(…, width=120, sort_dicts=False)` | 按字段顺序、限宽打印嵌套结构 |

### 运行方式

```bash
python realtime_data_queue.py
```

## 参数说明

| 名称 | 类型 | 默认值或范围 | 作用 |
| --- | --- | --- | --- |
| `data_sources` | tuple | 可多选 | 声明本会话要收哪几种数据 |
| `timeout` | float | 0.5 | `read()` 最多等待的秒数，超时返回 `None` |
| `sequence` | int | 只增 | 第几条数据，可判断是否丢包 |
| `received_monotonic` | float | 只增时钟 | 收到这条数据的时刻 |
| `age` | float | 秒 | 这条数据从采集到取出多旧 |

> `read()` 是**取走**，不是「看一眼」——取出来队列里就没有了，没有副本。
