## 本页目标

只控制**一个**轮子，把三件事看明白：`realtime.open()` 开实时会话、`motor_speeds.write()` 发速度、`valid_for` 让指令到期自动失效。这是后面所有运动例程的最小骨架。

## 前置条件

- 完成模块 1，能稳定连接
- **车轮架空**（轮子离地）
- 左轮接 M3、右轮接 M4

## 动手步骤

**1. 新建 `07_motor_control.py`**

**2. 写入代码**

```python
import time
import pymotion as pm

PORT = 4                                   # 3 接 M3 左轮，4 接 M4 右轮
RPM = 30                                   # 目标转速，正数正转，负数反转
MAX_RPM = 60                               # 允许的最高转速


def main():
    rpm = max(-MAX_RPM, min(MAX_RPM, RPM))          # 限幅，防止超速

    with pm.lite.connect(transport="wifi", timeout=15.0) as robot:
        with robot.control():                       # 电机动作前要拿控制权
            with robot.realtime.open(command_targets={"motor_speeds": (PORT,)}) as session:
                session.commands.motor_speeds.write({PORT: rpm}, valid_for=1.0)
                time.sleep(2.0)                     # 第 1 秒转，第 2 秒看自动停
                session.commands.motor_speeds.write({PORT: -rpm}, valid_for=2.0)
                time.sleep(1.0)
                session.commands.motor_speeds.stop()  # 主动停机，不等过期


if __name__ == "__main__":
    main()
```

**3. 运行**

```bash
python 07_motor_control.py
```

## 参数说明

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `PORT` | int | 3 / 4 | 左轮 M3、右轮 M4 |
| `RPM` | int | 本例 30 | 正数正转、负数反转 |
| `MAX_RPM` | int | 60 | 限幅上限，超了按比例削到 60 |
| `valid_for` | float | 秒 | 指令存活时间，到期设备端自动停机 |
| `command_targets` | dict | `{"motor_speeds": (端口,)}` | 声明本会话要控制哪些通道 |

## 预期效果与排查

轮子转 1 秒后**自己停下**（`valid_for` 到期），随后反转 1 秒被 `stop()` 提前停掉。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 轮子转不停 | 程序在 `with` 外发了指令，或会话没退出 | 确认在 `session` 内发送 |
| 完全不动 | 端口接错 | 把 `PORT` 换成 3 试 |
| 转速明显偏低 | `RPM` 超出 `MAX_RPM` 被限幅 | 看打印值是否被削 |
