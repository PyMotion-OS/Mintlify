## 本页目标

打开一个实时会话同时订阅两种传感器，从 `data_queue.read()` 里按来源取数据，并完整打印两种数据的结构。理解"数据是**持续推入队列**的，不是你去问它要"。

## 前置条件

- 完成例程 2.1
- 车轮架空（本例程会发一次速度指令）

## 动手步骤

**1. 新建 `08_realtime_data_queue.py`**

**2. 写入代码**

```python
import time
from pprint import pprint
import pymotion as pm

PORT_LEFT, PORT_RIGHT = 3, 4


def main():
    ultrasonic_data = None
    tracker_line_data = None

    with pm.lite.connect(transport="wifi", timeout=15.0) as robot:
        with robot.control():
            with robot.realtime.open(
                data_sources=("ultrasonic", "line_tracker"),   # 订阅两路数据
                command_targets={"motor_speeds": (PORT_LEFT, PORT_RIGHT)},
                frequency="high",                              # 采集频率
                data_queue_size=8,                             # 队列最多留 8 条
            ) as session:
                data_queue = session.data

                while ultrasonic_data is None or tracker_line_data is None:
                    sensor_data = data_queue.read(timeout=1.0)  # 队列空时最多等 1 秒
                    if sensor_data is None:
                        raise TimeoutError("没有收齐超声波和五路循迹数据")
                    if sensor_data.source == "ultrasonic":
                        ultrasonic_data = sensor_data
                    elif sensor_data.source == "line_tracker":
                        tracker_line_data = sensor_data

                session.commands.motor_speeds.write(
                    {PORT_LEFT: 30, PORT_RIGHT: 30}, valid_for=1)
                time.sleep(1)


if __name__ == "__main__":
    main()
```

**3. 运行**，观察两份结构打印

## 参数说明

`data_queue.read()` 返回的统一信封结构：

```
{
  "source": "ultrasonic",        # 数据来源：ultrasonic / line_tracker
  "data": {                      # 传感器自己的字段，随 source 变化
    "valid": true,
    "state": "valid",
    "age": 0.05,
    "distance": 235              # line_tracker 时这里是 is_detected 五元组
  },
  "sequence": 42,                # 递增序号，可判断是否丢包
  "received_monotonic": 12345.6, # 收到时刻（单调时钟，秒）
  "age": 0.03                    # 从采集到取出的时长
}
```

| 参数 | 类型 | 默认值或范围 | 说明 |
| --- | --- | --- | --- |
| `data_sources` | tuple | 本例两路 | 订阅的传感器，只订阅需要的能降负载 |
| `frequency` | str | `high` / `medium` / `low` | 约 20 / 10 / 5 Hz，默认建议 `high` |
| `data_queue_size` | int | 本例 8 | 满了丢最旧，宁小勿大避免拿到旧数据 |
| `read(timeout=1.0)` | float | 秒 | 队列空时阻塞等待，超时返回 `None` |
| `valid_for` | float | 秒 | 指令有效期，到期自动停 |

## 预期效果与排查

先打印超声波结构（含 `distance`），再打印五路循迹结构（含 `is_detected` 五元组），中间双轮转 1 秒。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `TimeoutError: 没有收齐...` | 某一路数据没上报 | 检查该传感器是否接好；把 `data_sources` 减到一个排查 |
| `sequence` 不连续 | 队列溢出丢包 | 增大 `data_queue_size` 或降 `frequency` |
| 拿到的 `data.age` 很大 | 处理太慢、队列积压 | 减小队列长度，处理逻辑别阻塞 |
